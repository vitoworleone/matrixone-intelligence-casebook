用户分组
管理用户 = 被分配了角色的 MO 用户。仅这些账户可以访问管理后台（含计费中心、Genesis 管理等模块），权限由角色决定。「添加管理用户」即从已注册的普通用户中选人并赋予角色，完成普通用户 → 管理用户的转变。
用户 邮箱 手机号 角色 分组 状态 最近登录 操作
普通用户 = 没有分配角色的 MOI 用户，只能访问 MOI 用户前端（数据连接、智能体、Genesis 等），无管理后台权限。在这里管理用户分组、启用/禁用账号；管理员可在「计费中心」给他们发放 Credit。
用户 邮箱 手机号 机构 分组 状态 最近登录 操作
用户分组 = 给用户打的多对多标签，可同时包含管理用户和普通用户。用于「计费中心 → 批量发放」按组发放 Credit、运营活动定向投放等场景。

角色权限说明

设计原则
运维管理员 管配置（技术域：渠道、模型、密钥、告警、平台监控等）。
运营管理员 管价值流转（业务域：定价、Credit 发放、用户与分组管理、账单等）。
两者操作面互斥。后续 MOI 后台新增模块按此原则归属。
角色 权限范围
超级管理员
super_admin
 全部权限（兜底）
· 唯一可创建 / 编辑 / 删除「系统管理员」
· 唯一可查看完整操作审计
· 自身不可被编辑或删除，系统初始化时唯一
· 通常 1 个，建议绑定对公邮箱或多人共管
系统管理员
sys_admin
 几乎等同超管，负责日常管理
· Genesis 所有模块（配置 + 业务）完整读写
· 计费中心所有模块完整读写
· 用户管理：可创建 / 编辑 / 删除「运维 / 运营 / 只读」三类管理用户；可管理普通用户和分组
· 唯一限制：不能管理其他系统管理员，也不能动超级管理员
运维管理员
ops_tech
 技术配置——保平台稳定运行
· Genesis 配置：渠道 / 模型 / 密钥 / 告警通知规则 / 操作审计——完整读写
· Genesis 监控：请求日志 / 运营看板 / 用量统计——完整读写
· 不可访问：计费中心（任何钱相关）、管理员角色分配
· 未来扩展：任何新模块的配置类页面默认归属本角色
运营管理员
ops_biz
 业务运营——管价值流转
· 计费中心：费用总览 / 用量明细 / 收支明细 / 价格设置 / Credit 发放——完整读写
· 用户管理：普通用户（增删改启停）/ 用户分组——完整读写
· Genesis 业务视图：运营看板 / 用量统计——只读（看活动效果）
· 不可访问：Genesis 任何技术配置（渠道 / 模型 / 密钥 / 告警规则）、管理员角色分配
· 未来扩展：任何新模块的定价、套餐、补贴、活动类页面默认归属本角色
只读成员
readonly
 观察者——所有页面只读
· 全部管理后台页面——只读
· 完全不可操作：不能改任何配置、不能发 Credit、不能创建 / 删除任何东西
· 敏感数据屏蔽：密钥明文不可见（仅看到掩码）、用户手机 / 邮箱部分掩码
· 适用场景：客户演示、新员工 onboarding、外部审计临时访问
