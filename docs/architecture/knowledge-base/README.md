# 知识库架构

本专题说明 MOI 如何把文件与业务数据组织为受控知识范围，并在 Agent 问答中提供可检索、可引用、可维护的证据。它关注产品架构与能力边界，不公开运行环境、内部实现细节或客户数据。

## 阅读顺序

1. [知识库资源架构](resource-model.md)：知识库、数据来源、数据域、语义配置与可检索版本如何关联。
2. [文档入库架构](document-ingestion.md)：文件如何经过解析、切分、向量化和发布，成为可检索内容。
3. [存储与索引架构](storage-and-index.md)：文档内容、向量、全文索引和业务表各自承担什么职责。
4. [语义配置架构](semantic-configuration.md)：术语、指标、关系和规则如何帮助理解文档与业务数据。
5. [Agentic RAG 查询架构](agentic-rag-query.md)：Agent 如何选择检索与数据查询能力，并形成带引用的回答。
6. [工作流与治理架构](workflow-and-governance.md)：来源处理、异步任务、版本发布和失败恢复如何协作。
