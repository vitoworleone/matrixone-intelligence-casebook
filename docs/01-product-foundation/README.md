# Product Foundation

This folder establishes the shared product logic across the cases: users, jobs to be done, capability boundaries, model and deployment decisions, cost, and governance.

## Data + AI foundation

[`data-ai/`](data-ai/) contains the public-safe research synthesis behind the casebook. It records product thesis, capability boundaries, and decision logic—not internal research files or vendor notes.

Create these documents before writing detailed PRDs:

- `product-vision.md`
- `target-users-and-jobs.md`
- `capability-map.md`
- `model-and-deployment-decisions.md`
- `cost-and-roi-framework.md`
- `security-and-governance.md`
