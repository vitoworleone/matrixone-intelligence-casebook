# Data + AI Foundation

This folder turns Data + AI research into decisions that a reviewer can inspect. It is intentionally not a research archive.

## Read in this order

1. [Product thesis](product-thesis.md): why an AI-ready data layer matters for enterprise AI.
2. [Capability map](capability-map.md): the end-to-end capabilities that turn raw data into trusted AI outcomes.
3. [Research-to-product decisions](research-to-product-decisions.md): what each research insight changed in the product design.

## Public boundary

- No employer product names, internal architecture, customer information, operating metrics, or source documents.
- External product claims require independent verification and citations before publication.
- Case-specific implementation evidence belongs in `docs/02-document-intelligence/` and `docs/03-agentic-data-workflow/`.
