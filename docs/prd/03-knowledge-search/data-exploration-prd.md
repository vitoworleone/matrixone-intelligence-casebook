# 数据探索需求文档

## 1. 产品目标

数据探索让用户在一组已完成嵌入处理的文件上进行多轮问答，并可从回答回溯到原始文件、页码、区域或媒体时间点。它将文件选择、检索、总结、引用卡片和原文预览组织为同一工作区。

## 2. 页面与对象

![文件预览、文件选择与智能检索的双栏工作台](../assets/data-exploration/dual-pane-workbench.png)

页面采用双栏布局：左侧为原文件预览，右侧为文件选择、问题输入、检索结果和会话控制。

| 对象 | 说明 |
|---|---|
| 已选文件 | 参与当前检索范围的、已完成嵌入的文件或数据单元 |
| 查询 | 用户输入的问题或关键词 |
| 回答 | 基于召回分段生成的总结，不应超出引用内容支持范围 |
| 参考分段 | 文本、图片、表格或音视频中的可追溯召回单元 |
| 原文预览 | 与选中分段联动的文件页、区域、行或时间区间 |

## 3. 文件选择

- 用户通过“选择文件”打开选择器；只显示已完成嵌入、可用于检索的对象。
- 可多选；未选择时确认按钮禁用；取消不保存本次变更。
- 再次打开选择器时默认勾选已选文件。
- 主页面展示已选数量，并可展开或折叠文件名列表；列表超过可视区域时独立滚动。
- 文件选择器应提供全选、取消全选和按名称搜索；没有符合“已完成嵌入”条件的对象时，说明原因并引导回数据处理页。

## 4. 查询与会话

### 4.1 执行

用户输入问题或关键词后，通过按钮或回车发起检索。前置校验：

- 无输入时提示补充检索内容；
- 无文件时提示先选择文件；
- 两者均缺失时优先提示选择文件。

查询执行期间保留上一轮结果并展示加载状态。新结果完成后追加到会话，不应无提示清空历史。

### 4.2 多轮与重置

- 多轮上下文默认开启，记忆轮数由后端配置。
- 关闭多轮后，本次查询不携带历史上下文。
- 已产生会话后显示重置入口；重置清空当前对话视图，但历史记录按产品留存策略保存。
- 输入区在执行期间禁用重复提交；失败后保留原问题，支持修改后重试。

## 5. 结果与原文定位

每轮结果包含用户问题、总结性回答和参考分段列表。

- 禁用的分段不得被召回。
- 分段卡片默认折叠，同一时刻最多展开一个；展开项高亮。
- 卡片展示来源文件名、内容摘要、字符数和召回信息；长文件名与长内容采用截断并提供完整查看。
- 文档分段打开时在左侧预览定位至对应页或高亮区域；图片显示原图；表格保持可读的原表结构；音视频定位至对应时间区间。
- 结果区需要区分“无召回”“召回成功但无法生成回答”“请求失败”三种状态，并保留可操作的下一步。
- 点击卡片后，左侧定位原始内容：文档定位页或区域，表格定位行，音视频定位起始时间但默认不自动播放。
- 图片和表格支持缩略预览与全屏查看；音视频支持播放、暂停、进度拖动及按分段时间区间播放。

## 6. 状态与验收

### 6.1 空状态

左侧预览根据当前状态提示下一步：选择文件、输入问题或点击参考分段；不展示虚构文件内容。

### 6.2 验收标准

- 用户可选择多个可检索文件并清晰查看已选范围。
- 查询校验、加载、历史与重置行为正确。
- 回答引用的分段可展开，并精确联动到原文页、区域、行或媒体时间。
- 不同模态的预览与播放规则正确，禁用分段不会进入结果。
