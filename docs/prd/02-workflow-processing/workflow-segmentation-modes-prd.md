# 工作流文本分段方式产品需求文档

## 1. 产品目标

提供单标志符与多标志符两种可配置分段模式，兼顾简单文本、结构化章节文本和需要语义连续性的长文档。

![多标志符分段配置](../assets/workflow-segmentation-modes/multi-separator-settings.png)

## 2. 单标志符分段

![单一分隔符的分段参数配置](../assets/workflow-segmentation-modes/single-separator-settings.png)

![自定义分隔符与长度、重叠参数](../assets/workflow-segmentation-modes/custom-separator-settings.png)

| 配置项 | 要求 |
|---|---|
| 分段标志符 | 必填；可选单换行、双换行、中英文句号、中英文感叹号、中英文问号、中英文分号、固定分隔线或自定义 |
| 自定义标志符 | 仅在选择自定义时显示，最长 10 个字符 |
| 分段最大长度 | 必填，范围 100–2000 个字符 |
| 分段重叠 | 必填，定义相邻分段的重叠字符数 |

## 3. 多标志符递归分段

![递归分段的优先级与分隔符配置](../assets/workflow-segmentation-modes/recursive-separator-settings.png)

- 用户以优先级顺序设置最多 5 个分段标志符，每个最长 10 个字符。
- 系统先以第一个标志符切分全文。
- 逐块检查长度，超过最大长度的块再使用下一个标志符递归切分。
- 全部标志符均已尝试且仍过长时，按最大长度强制切分。
- 每次成功切分后应用设置的分段重叠；后一块开头携带前一块结尾的指定字符。

## 4. 交互与校验

- 根据用户选择只展示当前模式相关的配置项。
- 对自定义标志符、最大长度、重叠长度和层级/数量进行前后端一致的必填、范围和特殊字符校验。
- 在保存前校验多标志符数量、长度、最大长度和重叠设置；后端必须按传入顺序执行递归算法。
- 重叠长度不得为负，且不得大于分段最大长度；空白或重复的自定义标志符不允许保存。
- 多标志符模式中删除某一项后，剩余项按界面顺序重新编号并作为实际优先级。

## 5. 验收要点

| 场景 | 验收标准 |
|---|---|
| 单标志符 | 可选择预设标志符或输入不超过 10 字符的自定义标志符 |
| 多标志符 | 最多 5 项，按用户定义顺序递归切分 |
| 超长内容 | 标志符耗尽后按最大长度继续切分 |
| 重叠 | 每次成功切分后后续分段带有指定长度的前文 |
| 校验 | 必填与范围错误无法保存，前后端结果一致 |
