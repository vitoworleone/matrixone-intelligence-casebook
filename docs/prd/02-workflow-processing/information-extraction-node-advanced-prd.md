# 信息提取节点增强产品需求文档

关联能力：本文件聚焦多文件提取、Schema 编辑/推理与字段溯源，是《信息提取节点功能增强产品需求文档》的后续迭代。

## 1. 多文件提取

### 1.1 输出模式

| 模式 | 行为 |
|---|---|
| 按文件独立提取 | N 个文件生成 N 个独立 JSON，文件名为 `原文件名.json` |
| 联合提取 | N 个文件作为一个整体生成 1 个 JSON；用户自定义结果名称 |

联合结果名称最多 50 个字符，只允许中英文字符、数字、下划线和中划线；为空或不合法时禁止保存。周期载入或载入触发出现增量文件后，联合模式需将已有文件与新增文件一起重新提取。

### 1.2 提取分块

- 经过解析节点时，以解析块为最小单位；不得切开单个解析块。
- 在模型上下文上限内尽量合并同一文件的多个块，但预留约 40% 上下文供模型输出。
- 不同文件的解析块不得合并为一个请求块。
- 开始节点直连时，PDF/Word 按页、Markdown/TXT 按空行、图片按完整图片作为最小单位，其他合并规则一致。
- 若经过解析节点下载多个文件，应合并各文件的 `tables` 和 `images` 目录，避免输出多个同类目录。

## 2. Schema 编辑

- 用户可手动创建 Schema，并在 JSON 配置和表单配置之间切换。
- 两种配置模式互不保留；切换后从当前模式重新配置。
- JSON 支持直接编辑或上传文件；上传仅校验类型和大小，语法由编辑器校验。
- JSON 语法无效时保存按钮不可用。
- 本迭代不限制字段数量和嵌套层级。

## 3. 智能 Schema 推理

![信息提取节点的智能 Schema 推理配置](../assets/information-extraction-node-advanced/schema-inference.png)

- 用户可提供一个文件、一个提示词或两者组合，自动生成 JSON Schema。
- 支持 PDF、DOCX、TXT、MD、JSON、PNG、JPG、JPEG、BMP、CSV、XLS、XLSX 等样例文件；单文件最大 10 MB。
- 文件和提示词至少提供一项，缺失时“生成”不可用。
- 生成结果自动进入可编辑的表单配置；用户可继续调整字段。
- 用于生成 Schema 的文件和提示词不保存，也不作为后续信息提取的样本。
- 因智能生成无法预估复杂度，该模式不限制字段数量和嵌套层级。

## 4. 字段来源追踪

除提取结果 `原文件名_extracted.json` 外，下载包增加 `原文件名_extracted_source.json`。

### 4.1 追踪结构

最小原子字段（如 string、number）增加来源数组；对象和数组只组织层级，不直接写入来源。

~~~json
{
  "extracted_value": "提取结果",
  "sources": [
    {
      "value": "原始片段",
      "block_id": "block-001",
      "file_id": "file-001",
      "file_name": "example.pdf",
      "page_number": 1
    }
  ]
}
~~~

- PPT 每页按一张处理；不能获得页码的文本文件页码为 1。
- 音视频来源额外记录 `start_time` 与 `end_time`。
- 当多个来源存在冲突时，系统选择一个最终值，但必须保留全部候选来源供审查。
- 仅叶子字段记录 `sources`；嵌套 Object/Array 自身不重复写来源，避免同一证据在父子层级重复与不一致。

## 5. 验收要点

| 场景 | 验收标准 |
|---|---|
| 独立/联合模式 | 文件数、输出数和命名规则正确；联合结果随增量重新提取 |
| 上下文分块 | 不切开最小块，保留输出空间，跨文件不合并 |
| Schema | JSON 与表单均可创建；语法无效时不能保存 |
| 智能推理 | 文件或提示词任一存在即可生成，生成内容可编辑且不保留样例 |
| 溯源 | 最小字段可定位到文件、块、页或时间段，冲突保留全部来源 |

## 6. 多文件运行与失败边界

- 独立模式中，一个文件失败不得阻塞其他文件；结果列表应能区分成功、失败和未处理，并保留失败文件的原因。
- 联合模式任一必需输入不可读取时，应整体失败，且不覆盖上一次成功产物。
- 周期载入触发联合重提取时，输出替换应是原子操作：新结果完整生成后再切换可见版本，避免用户下载到半合并的 `images/` 或 `tables/`。
- 来源文件、页面、块和时间区间是审查定位信息；展示时应可跳转到对应文件/片段，但不应把智能 Schema 推理阶段的临时样例混入正式结果。
