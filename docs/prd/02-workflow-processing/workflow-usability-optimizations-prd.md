# 工作流可用性优化产品需求文档

## 1. 目标

![工作流并行分支画布](../assets/workflow-usability-optimizations/parallel-branches.png)

通过命名校验、数据卷选择、文件范围、节点展示和多模态配置优化，使用户在少量操作内完成可执行工作流的创建与调整。

## 2. 创建工作流

### 2.1 目标数据卷选择

- 目标数据卷不可复用时，下拉列表必须展示已有名称。
- 可用数据卷排在前面；不可用数据卷置灰且排在后面，支持滚动加载。
- 用户尝试创建同名数据卷时即时提示“名称已存在”。
- 可用数据卷必须为空，不含工作流分支或处理数据；删除工作流但保留数据时，该数据卷仍不可用。

### 2.2 工作流名称

- 用户输入名称时实时校验重名。
- 重名时在命名阶段明确提示“名称已存在”，阻止用户继续创建无效配置。

### 2.3 一次处理的文件范围

| 项目 | 要求 |
|---|---|
| 支持模式 | 一次处理时支持“按文件类型”和“按文件”两种范围选择 |
| 非一次模式 | “按文件”标签置灰 |
| 初始状态 | 类型与文件默认均不选中；未选类型时文件列表显示空状态 |
| 文件列表 | 分页展示，每页 10 项；展示文件名、大小、类型，支持类型筛选 |
| 多数据卷 | 选择多个源数据卷时不支持按文件选择 |
| 状态重置 | 切换选择模式，或取消后重新选择文件类型时，已选文件状态清空 |
| 源数据卷变更 | 从单数据卷改为多个数据卷时，已选文件列表清空 |

## 3. 节点与画布

### 3.1 文案与命名

- 删除不准确的节点描述文案；只保留经过确认的说明。
- 节点卡片同时展示节点类型和节点名称。
- 同一工作流中节点名称唯一。默认名称为“节点类型 + 连续编号”，例如“文本解析节点 1”。
- 修改节点名称或删除节点不回收编号，后续创建继续递增。

### 3.2 载入触发

当源数据卷的数据载入任务完成一批文件时，立即启动关联工作流处理该批文件。界面文案统一使用“载入触发”。

### 3.3 画布交互

- 优化节点连线的可读性、连接反馈和布局一致性。
- 画布应让用户清楚辨别分支、汇聚和节点执行顺序。
- 连线到不兼容节点、形成非法拓扑或造成无输出路径时，应在操作当下提示并拒绝该变更，而不是等到执行阶段。

## 4. 节点配置优化

### 4.1 数据增强

“生成样本数”定义为**每个分块生成的最大问答数**。帮助文本必须明确该上限语义。

### 4.2 音视频说话人分离

音频与视频解析节点增加说话人分离能力，作为较低优先级增强项。

### 4.3 文本与图片解析开关

文本解析与图片解析节点提供以下独立开关：图片描述、OCR、文本嵌入。

- 图片解析节点的图片描述与 OCR 至少开启一项。
- 用户关闭最后一个已开启的图片描述或 OCR 时，提示“图片描述和 OCR 至少需启用一项，请保留其中一个”。
- 文本解析节点不受上述至少一项限制。

### 4.4 图片描述语言

- 提供图像描述输出语言选择，默认简体中文。
- 规划语言包括简体中文、繁体中文、英语、法语、西班牙语、日语、葡萄牙语。
- 当前阶段优先支持简体中文和英语，并按选择匹配对应图像描述模型。

## 5. 验收要点

| 场景 | 验收标准 |
|---|---|
| 数据卷选择 | 已占用或残留数据的数据卷不可选；名称冲突实时可见 |
| 工作流命名 | 名称输入阶段即可发现重复并阻止提交 |
| 文件范围 | 仅单数据卷的一次处理可按文件选择，切换条件时选择状态正确重置 |
| 节点名称 | 默认编号递增、名称唯一、卡片展示类型与名称 |
| 图片解析 | 用户无法同时关闭图片描述和 OCR |
| 多语言 | 默认中文且可选择英语；模型与语言选择一致 |
