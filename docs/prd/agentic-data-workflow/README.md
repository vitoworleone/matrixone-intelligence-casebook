# Case 02: Agentic Data Workflow

## Case goal

Show how an AI agent turns a multi-step request into controlled work: plans tasks, calls tools, tracks state, validates outputs, and escalates uncertainty to a person.

## Required artifacts

- `product-brief.md`
- `agent-design.md`
- `workflow-design.md`
- `tool-contracts.md`
- `state-and-memory.md`
- `human-in-the-loop.md`
- `failure-and-recovery.md`
- `evaluation-plan.md`

## Implementation boundary

The runnable prototype and its engineering documentation will belong in [`../../../product/`](../../../product/). Its workflow definition must be readable without running the app, and every tool must have a documented input/output contract.
