# 本地文件载入产品需求文档

## 1. 产品目标

在数据载入页面提供本地文件上传入口，减少用户先将本地数据转存至对象存储再导入平台的步骤。本期支持一次性、多文件上传，并将文件写入用户选择的数据卷。

## 2. 使用流程

![数据载入模式切换](../assets/local-upload/upload-mode.png)

~~~text
数据载入页面
  ↓
选择“本地载入”
  ↓
选择目标数据卷
  ↓
拖拽或选择本地文件
  ↓
检查数量、大小和格式
  ↓
确认并执行一次性载入
  ↓
在数据卷中查看文件及来源路径
~~~

## 3. 页面与交互

### 3.1 载入模式

页面顶部提供“连接器载入”和“本地载入”两个入口。选择本地载入后显示文件选择区、目标数据卷选择器和已选文件列表。

- 本地载入固定为一次性任务，不显示调度或持续载入配置。
- 支持拖拽文件到上传区域，或点击选择文件。
- 选择文件后才展示文件列表与确认操作。

### 3.2 文件列表

| 字段 | 说明 |
|---|---|
| 文件名 | 本地文件名称 |
| 文件路径 | 本地来源路径，用于载入记录与问题排查 |
| 文件大小 | 原始文件大小 |
| 类型 | 文件类型 |

系统支持一次选择多个文件。重名文件在本期不额外处理，按所选文件分别载入。

## 4. 文件范围与限制

| 类别 | 支持格式 |
|---|---|
| 文本与文档 | TXT、PDF、PPT、DOC、Markdown、DOCX、PPTX |
| 音频 | WAV、MP3、AAC、FLAC |
| 视频 | MP4、MOV、MKV |
| 图片 | PNG、JPG、JPEG、BMP |

| 限制 | 规则 |
|---|---|
| 单次文件数 | 最多 10 个 |
| 单文件大小 | 不超过 20 MB |
| 载入方式 | 仅支持一次性载入 |
| 文件夹 | 本期不支持上传文件夹 |
| 失败重试 | 本期不提供单文件或批量重试 |
| 页面刷新 | 未提交的文件选择不保留，刷新后需重新选择 |

## 5. 载入记录

提交后，系统将每个文件写入目标数据卷，并保留文件名、来源路径、大小和类型。载入完成后，用户可从数据载入页面的数据源类型中选择“本地数据”，并在目标数据卷内查看已导入的文件。

## 6. 验收标准

| 编号 | 验收项 |
|---|---|
| AC-01 | 数据载入页面可在连接器载入与本地载入之间切换。 |
| AC-02 | 本地载入支持拖拽和文件选择两种方式。 |
| AC-03 | 已选文件列表完整显示文件名、来源路径、大小和类型。 |
| AC-04 | 单次超过 10 个文件或任一文件超过 20 MB 时，阻止提交并提示限制。 |
| AC-05 | 支持列表中的全部文件类型；不支持格式不可提交。 |
| AC-06 | 本地载入不展示周期、持续或调度配置，并以一次性任务执行。 |
| AC-07 | 成功载入后，目标数据卷可查看对应文件及其来源路径。 |
