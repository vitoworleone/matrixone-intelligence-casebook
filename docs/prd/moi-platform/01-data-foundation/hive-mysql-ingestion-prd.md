# Hive 与 MySQL 结构化数据接入产品需求文档

## 1. 产品目标

支持从 Hive 和 MySQL 将数据库表全量或持续同步到工作区内部表，并在一致性、吞吐量和可恢复性之间提供明确的可配置策略。

## 2. 连接器

| 连接器 | 连接信息 | 用途 |
|---|---|---|
| Hive | 1–3 组主机/端口；LDAP 用户名密码或 Kerberos Keytab、krb5 配置 | 仅载入 |
| MySQL | 主机、端口、用户名、密码 | 仅载入 |

## 3. 载入配置

![数据库表载入的分区与字段选择](../assets/hive-mysql-ingestion/partition-and-field-selection.jpg)

| 配置项 | 规则 |
|---|---|
| 源类型 | Hive 或 MySQL；连接器列表仅展示对应类型 |
| 源表 | 从连接器可访问的数据库表中选择 |
| 载入模式 | 一次载入（全量）或实时同步（首次全量、后续增量） |
| 目标表 | 选择已有表或基于源表 Schema 创建新表 |
| 已有表策略 | 追加写入（默认）或覆盖写入；覆盖相当于先清空目标表 |
| Schema 校验 | 已有表至少校验字段名；名称不一致时禁止创建任务 |

创建新表时展示源表名称、描述、字段名、默认映射类型、主键、列描述和默认值。表名、字段名不可修改；映射类型可调整。

### 3.1 同步事务策略

| 策略 | 行为 | 适用场景 |
|---|---|---|
| 单事务 | 任一行失败即回滚本次整体写入 | 小数据量或强一致性 |
| 分区事务 | 分区独立提交，失败只回滚当前批 | 大数据量 |

分区支持按行数或按字段值：

- 按行数：指定唯一字段（可复合），排序后按批大小切分；字段不唯一时无法保证一致性。
- 按字段值：只选择一个字段，每个取值作为一个事务。

## 4. 类型映射

### 4.1 Hive

| Hive 类型 | 目标类型 |
|---|---|
| TINYINT、SMALLINT、INT、BIGINT、FLOAT、DOUBLE、DECIMAL | 同类数值类型 |
| STRING | TEXT |
| VARCHAR、CHAR、BOOLEAN、DATE、TIMESTAMP、BINARY | 同类类型 |
| ARRAY、MAP、STRUCT、UNIONTYPE | TEXT，源端先序列化为 JSON |
| 其他类型 | TEXT |

### 4.2 MySQL

| MySQL 类型 | 目标类型 |
|---|---|
| 整数类 | TINYINT、SMALLINT、INT、BIGINT；MEDIUMINT 映射 INT |
| 布尔类 | TINYINT |
| DECIMAL、NUMERIC、FLOAT、DOUBLE | 对应数值类型 |
| CHAR、VARCHAR、TEXT | 对应字符或 TEXT 类型 |
| BINARY、VARBINARY、BLOB | 对应二进制或 BLOB 类型 |
| ENUM、SET | VARCHAR |
| DATE、DATETIME、TIMESTAMP、TIME | 对应时间类型 |
| JSON | JSON |
| GEOMETRY 与其他未知类型 | TEXT |

## 5. 任务运行与恢复

列表新增连接器类型、实时同步模式、进度和导入行数。文件型结构化数据以“成功行数/总行数”展示进度；数据库全量任务同样按行数展示。实时同步任务正常情况下持续处于运行中。

| 操作 | 一次载入 | 实时同步 |
|---|---|---|
| 暂停 / 恢复 | 支持；单事务恢复等同继续未完成事务 | 支持；全量阶段单事务恢复可能等同重新运行 |
| 重新运行 | 支持；从头导入并确认是否清空目标表 | 支持 |
| 编辑 | 仅暂停时可编辑载入模式 | 仅暂停时可编辑载入模式 |
| 删除 | 停止、完成或失败时可删除 | 停止或完成时可删除 |

详情页展示连接器、源表、模式、同步策略、冲突处理、目标表、状态、进度、导入行数、最近开始/结束时间和错误日志。

## 6. 验收标准

| 编号 | 验收项 |
|---|---|
| AC-01 | 可创建 Hive 与 MySQL 载入连接器并选择源表。 |
| AC-02 | 支持一次全量和首次全量后持续增量两种模式。 |
| AC-03 | 可选择单事务或两类分区事务，并按策略处理失败回滚。 |
| AC-04 | 新建表可调整类型映射；已有表字段名不匹配时禁止创建任务。 |
| AC-05 | 类型按定义映射，复杂或未知类型降级为 TEXT。 |
| AC-06 | 可查看行级进度、状态和错误日志，并按规则暂停、恢复、重跑、编辑和删除。 |
