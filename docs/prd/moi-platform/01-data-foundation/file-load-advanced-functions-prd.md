# 数据载入增强功能产品需求文档

## 1. 产品目标

为载入任务补充文件夹上传、压缩包解压、重复文件处理与文件筛选能力，以支持文件结构复杂、来源冗余的数据导入场景，并提升载入后数据集的可用性。

## 2. 适用范围

| 能力 | 本地上传 | 连接器载入 |
|---|---:|---:|
| 任意文件类型上传 | 支持 | 按连接器能力 |
| 文件夹上传 | 支持 | 按连接器能力 |
| 自动解压 | 支持 | 支持 |
| 去重 | 支持 | 支持 |
| 文件类型与路径筛选 | 不支持 | 支持 |

本地上传不再按工作流可直接处理的格式限制文件类型；无法直接解析的文件可以由后续的自定义处理节点处理。

## 3. 本地文件夹上传

用户可通过拖拽或文件选择器导入文件夹。上传列表保留本地目录层级，写入数据卷时文件平铺存储，因为数据卷不维护文件夹结构。

| 限制 | 规则 |
|---|---|
| 单次文件数 | 最多 20 个；超过后阻止上传并提示重新选择 |
| 单文件大小 | 不超过 200 MB；超过后阻止上传并提示重新选择 |
| 支持内容 | 普通文件、文件夹和压缩包 |

## 4. 自动解压

### 4.1 支持格式

`.zip`、`.rar`、`.7z`、`.tar.gz`、`.tar.bz2`、`.tar`

### 4.2 解压规则

- 默认忽略压缩包内目录结构，将所有解压文件写入同一层级。
- 保持原始目录结构作为预留能力，当前不可选择。
- 支持递归解压，直至嵌套压缩包全部展开。
- 无论成功或失败，原压缩包均不写入数据卷。
- 解压失败（损坏、需要密码等）按单文件载入失败处理，并在任务详情记录错误原因。
- 部分文件解压成功时，成功文件继续载入；失败文件单独记录失败日志。
- 任务详情展示解压后的文件列表，而非压缩包条目。

## 5. 重复文件处理

### 5.1 判断规则

用户可选择以下任一或两项规则：

| 判断项 | 含义 |
|---|---|
| 文件名 | 与已有文件名称相同则视为重复 |
| MD5 | 文件内容哈希相同则视为重复 |

两个判断项同时勾选时为“或”关系，并先执行文件名判断，再执行 MD5 判断。默认不勾选，表示所有文件均保留。

### 5.2 处理策略

| 策略 | 行为 |
|---|---|
| 跳过 | 不接收与已有文件重复的文件，保留最早导入的文件 |
| 覆盖 | 用最新文件替换命中的已有重复文件；若命中多个内容相同的文件，全部覆盖 |
| 不启用去重 | 保留全部文件；出现重名时系统以追加序号或内部唯一标识方式生成可区分名称 |

只有启用了至少一个判断项时才可选择跳过或覆盖；否则处理策略不可编辑。MD5 用于判定文件内容是否完全一致。

## 6. 文件筛选

筛选仅适用于连接器载入，不适用于本地上传。筛选基于用户在载入文件列表中勾选的文件，而不是数据源中的全部文件；任务开始前可配置，暂停任务时不可编辑。

### 6.1 文件类型筛选

未指定类型时允许全部类型。预设分类用于简化选择：

| 分类 | 扩展名 |
|---|---|
| 文档 | doc、docx、ppt、pptx、txt、md、pdf、xlsx、xls、csv、eml、html |
| 图片 | jpg、jpeg、bmp、png |
| 音频 | wav、mp3、aac、flac |
| 视频 | mp4、mov、mkv |
| 其他 | 不属于上述分类的其他文件 |

### 6.2 路径正则筛选

用户可以填写正则表达式，对文件路径（含文件名与扩展名）进行进一步过滤。根目录以导入列表第一层为准，路径形式例如 `/report.pdf`。

- 文件类型筛选先执行，正则表达式在其结果上继续过滤。
- 空正则不执行路径过滤。
- 压缩包内文件在解压后参与筛选。
- 任务详情中需要展示已选择的文件类型与正则表达式。

| 场景 | 示例正则 | 示例匹配 |
|---|---|---|
| 根目录中的任意文件 | `^/[^/]+$` | `/report.pdf` |
| 任意层级的 TXT 文件 | `^.*/[^/]+\\.txt$` | `/a/b/readme.txt` |
| 指定目录下所有文件 | `^/reports/2025/` | `/reports/2025/a/report.pdf` |
| 文件名以日期开头 | `^.*/\\d{4}-\\d{2}-\\d{2}[^/]*$` | `/a/2025-08-07_report.pdf` |

## 7. 任务详情与日志

载入任务详情新增以下配置与执行信息：

| 信息 | 说明 |
|---|---|
| 解压策略 | 默认平铺或预留目录保持策略 |
| 去重逻辑 | 文件名、MD5 及对应处理策略 |
| 处理范围 | 已选择的文件类型和路径正则 |
| 文件级结果 | 原文件、解压产物、跳过、覆盖、成功、失败及原因 |

## 8. 验收标准

| 编号 | 验收项 |
|---|---|
| AC-01 | 本地上传支持任意文件类型、文件夹与压缩包，并正确执行 20 文件、200 MB 限制。 |
| AC-02 | 解压支持六种指定格式、递归解压、部分成功和失败日志；压缩包本身不保留。 |
| AC-03 | 默认解压结果平铺；目录保持选项处于不可选状态。 |
| AC-04 | 文件名与 MD5 可独立或组合启用，组合时按“或”关系判断。 |
| AC-05 | 跳过与覆盖仅在启用重复判断后可选，并按策略更新文件结果。 |
| AC-06 | 连接器载入可按类型和路径正则依次筛选；本地上传不展示该筛选。 |
| AC-07 | 任务详情可查看解压、去重、筛选参数及每个文件的最终处理结果。 |
