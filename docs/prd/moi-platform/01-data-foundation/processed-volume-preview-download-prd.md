# 处理数据卷展示、预览与下载产品需求文档

## 1. 产品目标

适配文本、图片、音频、视频、清洗结果和数据增强结果等多种工作流终态，提供一致的文件列表、详情预览与可消费的下载格式。

## 2. 文件状态与列表

处理文件状态统一为：待处理、处理中、处理完成、处理失败。列表支持按文本、图片、音频、视频分类筛选；文档扩展名分别展示，不将同类扩展名合并为一个类型。

文件详情入口统一命名为“文件处理详情”。文件列表支持按块 ID 和识别内容搜索。

## 3. 终态展示

| 最终节点 | 展示内容 | 下载内容 |
|---|---|---|
| 音频/视频解析 | 片段列表，含块 ID、时间范围、说话人、识别文本 | 完整分段 JSON |
| 清洗 | 与解析块同结构，内容替换为清洗后结果 | 清洗后 JSON |
| 数据增强 | 问答对列表、总条数与分页 | 文本/图片：`full.md` + 每文件 JSONL；音视频：JSONL |

数据增强详情中每行是一条完整问答对；本期不支持在该页搜索或删除。

```json
        "speaker": "Speaker 1",
        "text": "识别文本"
      }
    }

```

## 4. 多媒体预览

音频预览弹窗提供文件名、播放进度、当前时间、播放/暂停控制，默认暂停。视频使用相同的打开与控制逻辑。

## 5. 接口行为

文件详情接口按结果类型返回：

| `type` | `items` 内容 |
|---:|---|
| `0` | 解析/清洗后的内容块 |
| `1` | 数据增强生成的问答对 |

返回总数用于分页。原始下载接口沿用相同入口，但根据最终节点生成 JSON、JSONL、Markdown 和相关资源包；问答对 JSONL 不依赖嵌入状态。

## 6. 验收标准

| 编号 | 验收项 |
|---|---|
| AC-01 | 列表正确展示四类文件、四种处理状态并支持规定的搜索与筛选。 |
| AC-02 | 音频和视频解析结果按块展示时间、说话人和文本，且可下载 JSON。 |
| AC-03 | 清洗终态展示和下载清洗后内容。 |
| AC-04 | 数据增强终态按问答对分页展示，并按文件类型导出正确格式。 |
| AC-05 | 音视频可在弹窗中播放、暂停与查看进度。 |
| AC-06 | 文件详情接口按类型返回块或问答对，并携带总数。 |
