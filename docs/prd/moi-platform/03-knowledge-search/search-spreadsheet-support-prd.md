# Search 图表分析支持 Excel 与 CSV 需求文档

## 1. 产品目标

让用户将 CSV、XLS 和 XLSX 文件导入为可查询的表格数据，并在结构化数据分析模式中对已导入表格进行自然语言查询、生成数据结果和图表，同时保留来源文件的下载与追溯能力。

## 2. 用户流程

~~~text
选择表格文件 → 选择工作表 → 定义表头与数据起始行
→ 识别列结构 → 编辑字段信息 → 保存载入设置 → 导入并处理
→ 在结构化数据分析中选择表格文件 → 查询、图表与来源下载
~~~

## 3. 文件导入

### 3.1 支持范围

- 支持 CSV、XLS 和 XLSX。
- 一个工作簿可包含多个工作表；载入的最小单位为工作表。
- 用户可选择一个或多个工作表，但至少选择一个；未选中的工作表不可切换或编辑。

### 3.2 载入设置

| 配置 | 默认 | 规则 |
|---|---|---|
| 数据包含表头 | 选中 | 取消后表头行不可编辑，数据起始行重置为 1 |
| 表头行 | 1 | 仅在包含表头时可编辑；最小值为 1 |
| 数据起始行 | 2 | 必须大于表头行；无表头时默认 1 |
| 结构识别 | 自动执行 | 用户修改行号后可再次识别并覆盖预览结构 |
| 字段信息 | 自动填充 | 可编辑表头、值类型和列备注 |

- 表头与值类型均完整后才能保存。
- 用户可重置可编辑字段，包括表头、值类型和列备注。
- 保存后返回文件列表并显示已完成设置；设置详情可查看但不可直接修改，修改需要通过重新载入或更新流程完成。

## 4. 文件列表与生命周期

已上传文件列表展示格式、解析或载入状态、操作和预览入口。删除文件会同时删除关联的数据表，需二次确认。用户可查看只读的载入设置，明确当前工作表、表头行、数据起始行和字段定义。

导入或识别失败时必须展示原因，例如文件损坏、无法识别工作表、行号非法或列类型冲突；用户可返回设置修复并重新处理。

## 5. 结构化数据分析

![Chat2BI 在表格文件与数据库表之间选择数据源](../assets/search-spreadsheet-support/data-source-selection.png)

### 5.1 数据来源选择

用户进入结构化数据分析模式后，显示单选的数据来源过滤器：

| 数据来源 | 行为 |
|---|---|
| 数据库表 | 保持既有数据库查询和结果行为；默认选项 |
| 表格文件 | 在已导入并可用的 CSV / Excel 工作表中执行查询 |

用户可在后续筛选器中进一步限定具体表、工作簿或工作表。只有选择结构化数据分析模式时展示该过滤器。

### 5.2 查询结果

- 表格文件查询的结果结构与数据库表查询一致：包含文字结论、数据结果、图表和引用。
- 引用区说明来自哪个文件与工作表，并支持下载对应来源文件。
- 查询应遵守已确认的表头、字段类型和数据起始行；不能将未导入或处理失败文件纳入查询。

## 6. 验收标准与限制

### 验收标准

- 用户可导入 CSV、XLS、XLSX，并按工作表选择处理范围。
- 表头、数据起始行、无表头状态、字段识别、编辑、重置和保存规则正确生效。
- 文件列表展示状态、预览、只读设置和删除影响。
- 结构化数据分析可在数据库表和表格文件间切换，并正确返回结果、图表与来源下载。

### 限制

- 复杂公式、宏、受保护工作簿、合并单元格和超大文件的兼容策略需另行定义。
- 解析结果依赖用户确认的载入设置；错误表头或起始行会影响查询质量。
- 示例和测试数据不得包含真实姓名、电话、学号或其他个人信息。
