# 工作流 Excel 与 CSV 文件处理产品需求文档

## 1. 产品目标

支持 XLS、XLSX 与 CSV 文件接入、预览、解析和分段，使表格内容、单元格图片及其 OCR/图像描述能够进入统一工作流。

## 2. 文件接入

| 能力 | 要求 |
|---|---|
| 格式 | XLS、XLSX、CSV |
| 数据源 | 可从已接入的数据中心选择；本期本地上传入口暂不支持 XLS、XLSX、CSV |
| 原文件 | 提供表格预览与原文件下载 |
| 工作流 | 创建工作流时，文档类型新增 XLS、XLSX、CSV |

## 3. Excel 解析

### 3.1 合并单元格

自动识别合并单元格并展开为独立单元格；原合并区域的内容填充到每个展开后的单元格。

### 3.2 图片

| 图片类型 | 提取与存放规则 |
|---|---|
| 嵌入单元格 | 提取图片至 `images`，执行 OCR 和图像描述；结果保留在对应单元格中 |
| 浮动图片 | 提取图片至 `images`，执行 OCR 和图像描述；作为该工作表末尾的独立解析项，不归属具体单元格 |

- 所有提取图片应同时生成可下载的图片目录。
- 后续优先级可为每个工作表生成 Markdown 表示。

### 3.3 解析输出

解析块至少包含文件名、工作表名、块序号、类型、单元格位置和内容。图片块增加 `level`（`ocr` 或 `caption`）与图片引用；浮动图片的 `location` 为空。

~~~json
{
  "sheet_name": "Sheet1",
  "index": 1,
  "type": "text",
  "location": "A1",
  "content": {"列名": "单元格文本"}
}
~~~

## 4. CSV 解析配置

![CSV 解析器的字符集、分隔符、定界符与表头配置](../assets/workflow-spreadsheet-processing/csv-parser-settings.png)

![CSV 与图片解析配置](../assets/workflow-spreadsheet-processing/csv-settings.png)

| 配置项 | 默认值 | 可选值 |
|---|---|---|
| 分隔符 | 逗号 | 逗号、分号、制表符、管道符、空格 |
| 定界符 | 双引号 | 单引号、波浪号、无 |
| 反斜杠转义 | 开启/关闭开关 | 用于区分数据内的分隔符 |

不支持自定义分隔符和定界符。

## 5. 分段结果

- Excel 按行分段，每行生成一个 `spreadsheet` 类型分段。
- 标题行与行内容按键值对组合。
- 工作表内的浮动图片各自生成独立图片分段。
- 分段内容应包含单元格内图片的 OCR 与图像描述。

~~~json
{
  "sheet_name": "Sheet1",
  "chunk_id": "chunk-001",
  "index": 1,
  "type": "spreadsheet",
  "content": {"字段 A": "值 A", "字段 B": "值 B"}
}
~~~

## 6. 验收要点

| 场景 | 验收标准 |
|---|---|
| 接入 | 三种格式均可从数据源接入，并可预览、下载；本地上传明确提示暂不支持 |
| 合并单元格 | 展开后每个单元格都有原合并内容 |
| 单元格图片 | OCR 与描述回写至对应位置 |
| 浮动图片 | 独立输出，位于工作表解析结果末尾 |
| CSV | 配置项可用，默认值正确，不支持任意自定义符号 |
| 分段 | 表格按行产生带工作表信息的键值对分段 |

## 7. 解析边界与失败处理

- 每个工作表独立维持行序；相同工作簿中的浮动图片排在所属工作表文本块之后，不能被误归入任意单元格。
- CSV 配置在解析前生效；分隔符、定界符或转义规则导致列数异常时，阻止生成错误分段并给出行号或格式原因。
- 图片提取失败不应丢弃整张表：保留可读单元格内容，并在图片项中记录处理失败状态。
