# Documentation

This repository separates product thinking from product implementation.

Start here: [产品全景与实习工作说明（中文）](product-overview.md) — product relationships, personal responsibilities, concrete workflow and knowledge-base rules, agent integration, and scenario-based validation. Includes handbook-informed explanations and links to public design cases, with material and version scope stated explicitly.

- [Research](research/): product, market, and technical research notes.
- [PRD](prd/): product framing, requirements, and design artifacts.
- [PoC](poc/): validation plans, acceptance criteria, and delivery retrospectives.
- [Architecture](architecture/): public product architecture and capability boundaries.
- [Evaluation](eval/): quality measurement methods and sanitized evaluation evidence.

Runnable prototypes, code, and engineering documentation will live in [`../product/`](../product/) when they exist.
Scenario-based product validation material lives in [`../storybook/`](../storybook/).
