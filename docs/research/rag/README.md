# MOI Knowledge Book

MOI Knowledge Book 是一个围绕企业知识构建、检索证据与引用回答的产品案例。它关注复杂资料如何进入受控的知识范围，并在用户提问或 Agent 任务中以可核验的证据被使用。

## 案例阅读

- [可追溯检索设计](moi-knowledge-book-rag-design.md)：从知识构建到回答引用的端到端产品设计。
- [能力范围与设计取舍](moi-knowledge-book-rag-scope.md)：第一阶段优先解决什么、需要验证什么，以及刻意不做什么。

## 保留调研资料

- [RAG 能力与平台调研](rag-research.md)：MaxKB、RAGFlow、AnythingLLM、DataFlow 等产品与能力观察。
- [RAG 策略与选型](rag-strategy-and-selection.md)：是否投入 RAG、优先场景与选型维度。

> [!NOTE]
> 调研资料用于理解市场与方法，不等同于 MOI Knowledge Book 的产品承诺。案例范围以“可追溯检索设计”和“能力范围与设计取舍”为准。
