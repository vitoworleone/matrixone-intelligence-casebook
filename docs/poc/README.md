# POC 方案集

## 01. 人才筛选与招聘决策

### 数据对象

- 岗位：岗位名称、职责、必备技能、加分项、地点、职级和招聘状态。
- 投递：候选人、投递岗位、投递时间、招聘阶段和负责人。
- 简历：原始文件、解析文本、结构化画像、向量、解析状态和人工修订记录。
- 评估：评分维度、总分、排序、评语、证据片段、审核人与回写状态。

### POC 流程

1. 从招聘系统同步岗位、投递和附件，建立岗位、投递、简历文件、评估结果四张关联表。
2. 数字版 PDF/Word 走文本解析；扫描件走 OCR/VLM；保留文件地址、页码和解析状态。
3. 以固定 Schema 抽取教育、工作经历、技能、证书、语言、项目经验和工作年限；失败记录进入重试队列。
4. 为简历文本和技能生成向量，同时保留地点、年限、公司、职位等结构化过滤字段。
5. 招聘人员用自然语言搜索候选人，连续追加筛选条件；结果展示命中理由、原文片段和关键字段。
6. 岗位关闭后按固定 Rubric 批量评分，输出维度分、排序、分层和待复核项；HR 确认后回写招聘系统。

### POC 页面与输出

- 候选人搜索：自然语言条件、结构化过滤、候选人对比、来源证据。
- 批量评分：任务进度、失败重试、评分明细、人工复核、回写结果。
- 数据质量：缺附件、解析失败、字段缺失、孤儿投递、重复候选人。

### 实现组件

REST 接入、文件解析、条件路由、信息提取、向量检索、SQL 过滤、批量任务、人工审核和 MySQL/API 回写。

## 02. 动态定价与运营分析

### 数据对象

- 行程与订单：出发/到达区域、时间、价格、取消和供需状态。
- 司机与车辆状态：位置、在线时长、接单率和利用率。
- 外部变量：天气、节假日、活动日历和区域事件。
- 特征与决策：城市、日期、区域、特征版本、策略版本、定价结果和实际结果。

### POC 流程

1. 历史订单和规则日志以全量加增量方式载入；外部数据按小时或天更新。
2. 以城市、日期、区域和时段为主键计算需求、供给、取消率、等待时长、司机利用率和外部环境特征。
3. 产出可复用特征表，训练、回放和运营分析使用同一套特征口径。
4. 模型训练、在线推理和策略执行由独立服务承接；平台保存特征版本、策略版本和决策日志。
5. 运营人员通过问数查看区域高峰、天气影响、价格变化和供需差异，按城市、区域和时段下钻。
6. 选择历史时段运行策略回放，对比基准与候选策略的收入、取消率、等待时间和司机利用率。

### POC 页面与输出

- 特征数据集：字段字典、刷新时间、质量状态和版本。
- 运营分析：区域热力、趋势图、维度切片和自然语言问数。
- 策略回放：输入时段、策略参数、对照指标和差异明细。

### 实现组件

数据库/API 接入、增量水位线、SQL 特征计算、周期调度、指标语义层、NL2SQL；实时 GPS、空间计算、低延迟推理和模型实验通过专项服务集成。

## 03. 自助知识助手

### 数据对象

- 文件库：PDF、Word、截图、音视频、上传人、权限和处理状态。
- 处理流水线：解析、OCR/ASR、分段、嵌入、索引和发布版本。
- 知识库：数据源范围、切片策略、检索配置、版本和引用信息。

### POC 流程

1. 用户上传文件后，按类型进入文档、图片、音频或视频解析路径。
2. 每个文件显示解析、分段、嵌入、索引和就绪状态；异常可定位到步骤后重新执行。
3. 管理员复制已有处理流水线，调整解析、分段和检索配置后发布新版本。
4. 新建知识库时选择文件范围和已发布的流水线；知识库保留发布记录和数据源清单。
5. 在知识库内直接测试问题，展示检索片段、回答、文件来源、段落位置和跳转入口。

### POC 页面与输出

- 文件处理中心：上传、状态、失败原因和重新运行。
- 工作流管理：版本、复制、发布和运行记录。
- 知识库测试台：问题、检索 chunks、引用定位和回答质量标注。

### 实现组件

多模态解析、工作流版本、知识库构建、RAG 问答、引用展示和运行日志。

## 04. 运营数据问数与趋势分析

### 数据对象

- 交易事实：交易时间、站点/区域、金额、流量、车型或业务类型。
- 维度：区域、站点、日期、产品、客户或渠道。
- 指标：收入、交易量、峰谷、同比、环比、客单价和异常定义。

### POC 流程

1. 导入交易事实表和维度表，检查主键、日期完整性、金额范围和维表关联。
2. 配置表关系、指标公式、字段描述、同义词和可用筛选维度。
3. 将趋势、同比环比、Top N、区域对比和异常明细沉淀为 SQL 模板。
4. 用户以自然语言提问；系统识别指标、时间范围、维度和排序要求后执行安全 SQL。
5. 结果返回表格、趋势图、柱状图和可追问上下文；异常结果可下钻到交易明细。

### POC 页面与输出

- 语义配置：表关系、指标口径、同义词和示例问题。
- 分析工作台：问题、SQL、结果表、图表、筛选条件和导出。
- 数据质量：导入批次、行数校验、延迟和异常记录。

### 实现组件

关系型数据连接、全量导入、SQL 工作流、指标语义层、NL2SQL 和图表卡片。

## 05. 邮件到研发事项自动化

### 数据对象

- 邮件：发件人、主题、正文、附件、邮件链、时间和文件夹。
- 分类：进展、决策、风险、新需求、缺陷、待确认等多标签。
- 实体：项目、人员、日期、金额、SLA、文件和产品模块。
- 研发事项：标题、描述、标签、优先级、关联邮件、评论和处理状态。

### POC 流程

1. 配置邮箱授权、可读取文件夹和研发事项平台连接，先对历史邮件进行空跑。
2. 清理 HTML、签名、转发引用链和重复附件，统一解析正文、PDF、Word、Excel 和图片。
3. 根据已有事项库和项目词表做分类、实体抽取和归属消歧。
4. 高置信度邮件匹配已有事项并追加评论；新需求或缺陷创建新事项。
5. 不确定邮件进入人工 Triage 队列；审核结果反哺分类规则和示例集。
6. 持续运行后统计处理量、自动写入率、人工修订率和漏分项。

### POC 页面与输出

- 空跑对比：原邮件、分类结果、拟写入事项、差异和接受/拒绝。
- Triage 队列：低置信度原因、编辑、确认和批量处理。
- 运行看板：处理量、失败、待审、事项写入和规则效果。

### 实现组件

邮箱接入、附件解析、实体提取、知识库消歧、工作流路由、事项平台双向写入和审核闭环。

## 06. 设备可靠性湖仓

### 数据分层

- Bronze：原始设备遥测、维修工单、资产主数据、同步批次和水位线。
- Silver：清洗读数、设备状态、停机会话、资产层级和丰富后的工单。
- Gold：停机与工单匹配、可用率、利用率、维修时长、故障间隔和月度可靠性指标。

### POC 流程

1. 将遥测和维修工单分别进入 Bronze，记录源时间、载入时间、批次和重复检测结果。
2. 清洗时间戳、设备标识和测点值，计算设备状态；未知状态按规则前向填充并保留原始标识。
3. 用窗口函数识别连续停机/运行会话，输出会话起止时间、时长、原因和设备层级。
4. 清洗工单状态、类别、维修时间和资产映射，补齐与设备层级相关的业务属性。
5. 先按时间重叠匹配停机会话与工单，再按最近时间窗口补充匹配；所有匹配保留规则版本和证据。
6. 生成可靠性指标和 BI 数据集，支持按资产、时间、状态和工单类型分析。
7. 对每层执行行数、空值、时序连续性、重复、工单关联和指标合理性检查。

### POC 页面与输出

- 数据血缘：源表、Bronze、Silver、Gold 的任务依赖和最近运行状态。
- 设备事件：状态时间线、停机会话、关联工单和原始读数。
- 可靠性看板：可用率、利用率、MTBF、MTTR、停机原因和月度趋势。
- 问数工作台：围绕设备、时间、工单和指标的自然语言分析。

### 实现组件

关系型接入、增量水位线、SQL/Python 工作流、窗口计算、质量门禁、调度、语义层和 BI/NL2SQL。

## 07. RFQ 自动评估

### 数据对象

- 能力知识：产品资料、技术白皮书、资质、交付经验和标准条款。
- RFQ 条目：工作表、章节、条款、要求类型、应答栏和备注栏。
- 评估结果：合规、不合规、存疑、证据引用、建议回复和人工结论。

### POC 流程

1. 将能力文档解析入库，保留原文件、页码、章节和可检索切片。
2. 上传 RFQ Excel，识别工作表、表头、章节、说明性文本和可评估条目。
3. 对每条要求检索能力知识，输出判断、引用、理由、缺失信息和建议回复。
4. 存疑条款暂停任务并向用户发问；用户补充信息后从断点继续评估。
5. 用户在结果列表中修改结论和回复，系统记录人机差异。
6. 将结果回填到应答模板，输出可提交的 Excel 和评估汇总。

### POC 页面与输出

- RFQ 上传与条目识别。
- 条目评估：进度、状态、引用、人工澄清、编辑和筛选。
- 结果：合规统计、待补资料清单、导出文件和准确率对比。

### 实现组件

PDF/Word/Excel 解析、知识库检索、逐条 Agent 任务、暂停恢复、人机协作和模板回填。

## 08. 制造运营预测助手

### 数据对象

- 生产记录：批次、设备、工序、状态、时间、产能和异常事件。
- 预测结果：预测值、实际值、偏差、影响因子、模型版本和生成时间。
- 报告与告警：早报、午报、异常提醒、订阅人和发送状态。

### POC 流程

1. 从生产数据平台增量同步生产记录，使用水位线管理同步范围和回退。
2. 按工厂、日期、设备、工序建立事实表和维度表，并执行空值、断档和跨表一致性检查。
3. 在固定时间执行取数、指标计算、预测服务调用、结果写入和报告生成。
4. 报告只基于结构化预测结果生成，生成后进行字段级数字校验。
5. 分析人员使用预定义意图和 SQL 模板追问；系统提取参数后执行模板，不开放任意写 SQL。
6. 外部系统按授权范围拉取预测和告警结果；每天计算实际与预测偏差，形成校准输入。

### POC 页面与输出

- 预测结果表：预测、实际、偏差、模型版本和影响因素。
- 运营问答：意图模板、参数、结果和追问上下文。
- 报告与告警：发送记录、订阅人和失败重试。
- API 使用记录：调用方、范围、频率和审计日志。

### 实现组件

增量同步、DAG 调度、SQL/Python 节点、外部预测服务、报告生成、数字校验、模板化问数和 API 鉴权。

## 09. 教育内容智能服务

### 数据对象

- 内容资产：教材、题库、讲义、音频、视频、图片和元数据。
- 内容片段：章节、知识点、题型、难度、学段、语言、文本、关键帧和向量。
- 教学任务：答疑、检索、内容推荐、出题、批改和口语评测。

### POC 流程

1. 接入内容文件、结构化题库和外部内容接口，统一管理原始素材与处理结果。
2. 文档提取章节和表格；音频转写；视频生成转写和关键帧索引；图片经 OCR/VLM 处理。
3. 按学段、学科、章节、知识点、题型和难度为内容打标，并构建全文与向量索引。
4. 教师根据课程目标检索内容、生成练习或获得备课素材；学生获得带来源的答疑。
5. 将出题、批改、口语评测封装为独立技能，记录输入、输出、人工修改和反馈。

### POC 页面与输出

- 内容处理中心：素材状态、解析预览、标签和索引质量。
- 教师工作台：检索、选材、组卷和内容生成。
- 学生问答：问题、答案、引用来源和反馈。

### 实现组件

多源接入、多模态解析、内容标签、知识库、检索重排、技能编排和应用/API 发布。

## 10. 临床中心筛选

### 数据对象

- 中心画像：机构、科室、研究者、设备、床位、人员、历史项目和合规记录。
- 原始资料：历史问卷、公开试验记录、项目复盘和结构化业务记录。
- 评分结果：维度得分、综合分、风险标识、证据位置、评分版本和人工调整。

### POC 流程

1. 导入文档、公开记录和项目数据；数字化问卷与扫描件分别进入文本解析和 OCR/VLM 路径。
2. 抽取机构、科室、研究者、设备、床位、项目经验、招募能力和合规事件等字段。
3. 通过名称相似度、多字段校验和人工审核将不同来源的同一中心合并为统一画像。
4. 用户输入新项目需求，系统从招募、经验、资源、数据质量、合规和地域等维度评分并排序。
5. 候选列表展示综合分、维度分、风险标识和证据来源；用户可持续增加过滤条件。
6. 选择多个候选中心生成横向对比和筛选报告；项目实际表现回流后保留新的评分版本。

### POC 页面与输出

- 中心画像：统一名称、来源记录、冲突字段和审核历史。
- 候选推荐：Top N、评分拆解、证据回溯、比较和过滤。
- 项目报告：候选清单、维度对比、风险、推荐理由和附件。

### 实现组件

多源接入、文档抽取、实体解析、主数据治理、可配置评分、检索问答、证据引用和审核回流。

## 11. 企业经营问数与 BI

### 数据对象

- 财务与经营事实：收入、成本、利润、预算、实际、订单、区域和产品。
- 指标字典：预实比、毛利率、同比、环比、CAGR、客户贡献和行业对标。
- 分析任务：多维下钻、归因、异常解释、同业对比和管理层摘要。

### POC 流程

1. 连接 ERP、数据仓库和外部公开数据接口，按主题沉淀经营数据集。
2. 将指标定义、计算规则、字段同义词和口径差异写入语义层。
3. 以 SQL/代码工作流实现预实对比、区域/产品/工艺切片、Top N 和 CAGR 分析。
4. Agent 根据问题路由到分析模板或外部数据 API，返回表格、卡片和图表。
5. 管理人员从总结继续追问原因、下钻维度或查看明细；分析结果可嵌入现有办公系统。

### POC 页面与输出

- 指标中心：定义、公式、数据来源、更新时间和负责人。
- 经营分析：问题、调用的分析模板、表格、图表和引用口径。
- 管理摘要：关键变化、异常提示、下钻入口和外部对标。

### 实现组件

数据库/API 连接、SQL/代码工作流、知识库语义配置、工具路由、图表输出和嵌入式发布。

## 12. 报价邮件解析与业务写回

### 数据对象

- 邮件与附件：邮件头、正文、PDF、Excel、发送链和附件版本。
- 报价行：物料号、描述、数量、状态、交期、价格、币种、客户和销售人员。
- 主数据：联系人、销售人员、物料别名、状态码和业务编码。
- 写回记录：报价单头、报价明细、写入结果、失败原因和人工修改。

### POC 流程

1. 用户上传邮件文件或从邮箱批量读取邮件，拆分正文和附件。
2. 通过规则从收发件人链识别内部销售人员；清除签名和转发噪声。
3. 对扫描 PDF 使用视觉解析，对 Excel 识别有效表头与数据区域，跳过签名档和页脚。
4. 分批抽取报价字段并输出固定 JSON；字段缺失、低置信度和格式异常进入校对队列。
5. 先精确匹配物料号，失败时以描述和同义词进行相似匹配；自由文本状态映射为标准代码。
6. 用户在表格中编辑结果后生成报价单头和明细，批量写回业务数据库；失败项可单独重放。

### POC 页面与输出

- 邮件解析：原文、附件、提取表格、置信度和字段编辑。
- 物料匹配：匹配候选、相似度、替代料和人工选择。
- 写回任务：成功、失败、重试和已生成业务单据。

### 实现组件

邮箱/文件接入、邮件预处理、PDF/Excel 解析、JSON 提取、规则映射、向量匹配、数据库写回和任务重放。

## 13. 知识治理与问答运营

### 数据对象

- 源文件：文档、演示材料、图片、音视频、来源系统和版本。
- 知识对象：业务场景、流程、规则、角色、产品能力、标签和引用。
- 问答反馈：问题、答案、命中文档、错误类型、修复动作和复测结果。

### POC 流程

1. 通过 API 和人工上传接入资料，按格式和业务主题进入处理队列。
2. 解析文本、表格、图片和演示内容；对结构复杂材料保留页级预览和解析失败标记。
3. 按预设知识模板抽取字段，形成可检索、可筛选的知识对象。
4. 面向不同业务场景建立知识库，配置标签、检索范围、切片策略和权限。
5. 问答 bad case 关联到命中的知识切片，标注问题类型后发起修复、重新索引和复测。

### POC 页面与输出

- 资料处理中心：来源、版本、解析预览、模板抽取和入库状态。
- 知识运营台：知识对象、标签、切片、引用和权限。
- Bad case 看板：问题、命中片段、修复状态、复测结果和趋势。

### 实现组件

多模态解析、模板化信息抽取、知识库、引用追踪、反馈标注、重建索引和运营工作流。

## 14. 销售订单自动化

### 数据对象

- 订单邮件：正文、附件、发送人、客户、收件时间和处理状态。
- 订单字段：客户、物料、数量、价格、交期、币种、地址和备注。
- ERP 订单：订单编号、行项目、同步时间和回写状态。
- 周报：订单汇总、异常清单、收件人和发送记录。

### POC 流程

1. 监听指定邮箱或使用人工上传入口接收订单邮件和附件。
2. 解析邮件正文、PDF 和 Excel，抽取订单字段并高亮不确定内容。
3. 用户以表单/表格校对结果，复制标准格式文本或确认写入。
4. 按日从 ERP 获取订单数据，更新指定 Excel 模板的工作表和数据行。
5. 每周生成订单周报草稿，用户预览后发送到配置的收件人。
6. 管理员调整邮箱范围、同步频率、报表周期和收件人，无需重新部署。

### POC 页面与输出

- 订单处理台：原邮件、字段提取、置信度、编辑和确认。
- 同步任务：ERP 同步范围、执行记录和异常。
- 周报：数据预览、模板文件、收件人和发送历史。

### 实现组件

邮箱监听、附件解析、字段提取、人工校对、ERP/API/数据库连接、Excel 模板更新、调度和邮件发送。

## 15. 监管与金融数据分析

### 数据对象

- 市场数据：行情、指数、行业、技术指标和时间区间。
- 经营数据：损益、持仓、年度财务数据和衍生指标。
- 外部信息：新闻、公告和网页自动化获取的数据。
- 分析意图：指标查询、趋势判断、持仓变化、财务计算、事件解释和图表展示。

### POC 流程

1. 连接预计算后的市场和经营数据；外部新闻通过 API，网页数据通过受控的外部自动化服务获取。
2. 预先生成移动均线、成交量均线、连续满足条件天数、年度聚合和 CAGR 等派生指标。
3. Agent 识别问题意图、时间范围、标的和指标，必要时先追问缺失条件。
4. 将请求路由到 SQL、代码、数据库聚合、新闻 API 或外部自动化子流程。
5. 以表格、指标卡、图表和简短解释返回结果，并保留数据时间和计算口径。

### POC 页面与输出

- 意图路由：识别结果、参数、调用工具和执行记录。
- 分析结果：表格、图表、计算公式、数据截止时间和追问。
- 外部数据任务：调用状态、失败重试和数据刷新记录。

### 实现组件

多数据库/API 连接、预计算数据集、意图路由、SQL/代码节点、HTTP 工具、外部自动化调用和多模态回复。

## 16. 实验室设备数据平台

### 数据对象

- 设备与实验室：设备编号、设备类型、实验室、负责人、在线状态和权限范围。
- 采集数据：设备数据库记录、离线文件、测试批次、测点、图像、报告和时序数据。
- 解析规则：设备类型、字段映射、脚本版本、试运行结果和适用范围。
- 质量与告警：完整性、范围、一致性、异常标记、通知、处理记录和审计日志。

### POC 流程

1. 通过数据库连接、对象存储和人工上传接入设备数据；离线上传时填写设备、批次和测试类型等元数据。
2. 大文件存对象存储，Catalog 保存元数据、文件地址、生命周期信息和关联业务记录。
3. 根据设备类型路由到对应解析规则；规则包括字段映射、Python 扩展、试运行预览和版本。
4. 按设备和日期落表，对完整性、范围、一致性和异常值执行质量检查；异常数据保留并打标。
5. 处理后的数据按批次或增量推送到下游数据平台和业务数据库。
6. 按阈值、趋势和离群规则产生告警，并推送给责任人；采集、解析、出站和告警任务统一追踪。
7. 管理员按实验室和设备组查看运行状态，进入设备详情后查看参数趋势、异常和原始文件。

### POC 页面与输出

- 设备总览：在线、离线、异常、维护、分组和下钻。
- 设备详情：关键参数曲线、质量结果、告警、批次和文件。
- 规则管理：设备类型、规则版本、试运行、发布和回滚。
- 运行中心：采集、解析、出站、告警任务的状态、日志和重试。

### 实现组件

JDBC/ODBC 与对象存储接入、元数据表单、解析规则工作流、分区表、质量规则、告警、出站同步、行级权限和审计。
