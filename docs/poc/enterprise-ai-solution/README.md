# Case 03: AI Product Evaluation & PoC

## Case goal

Show how an AI product is evaluated, scoped, accepted, and reviewed before it is positioned for enterprise delivery, without exposing a real customer or internal project.

## Required artifacts

- `customer-problem-framing.md`
- `requirement-discovery.md`
- `solution-proposal.md`
- `poc-plan.md`
- `acceptance-rubric.md`
- `rollout-and-training.md`
- `delivery-risk-register.md`

The case must make scope, adoption, cost, security, and success criteria visible. A technically plausible demo without an acceptance plan is not a solution PoC.
