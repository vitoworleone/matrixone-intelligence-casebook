# SB-DI-011｜从活动截图生成可信海报

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 图像生成 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `draft` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证合成活动截图中的指定文字可被识别，并生成包含同一受控事实、可预览的海报草稿。

## 用户目标与风险

用户需要快速从截图制作宣传物。风险是识别错误、日期地点等关键信息被改写、额外事实被臆造或输出不可使用。

## 受控输入与前置条件

私有夹具含合成截图、事实清单、禁止项与视觉检查项，以版本和 SHA-256 冻结。需有隔离输出位置与图像处理能力。

## 产品路径

上传截图；确认识别文本与海报要求；生成草稿；预览并按事实清单核对后保存。

## 验收断言

- 指定文字、数字和日期被准确识别；低置信度字段应提示复核。
- 海报包含全部必备事实，且不包含禁止项或无来源信息。
- 输出可预览、格式正确并可关联本次输入和运行；失败状态可定位。
- 临时资源清理完成。

## 预期交付物、运行证据与变更影响

交付物为海报草稿和事实核对摘要。证据包括夹具校验、文字比对、禁止项扫描、预览检查和清理记录。变更 OCR、生成模型、提示词或导出逻辑必须重跑。

## 公开边界

不公开截图、海报、活动信息、用户标识或运行日志。
