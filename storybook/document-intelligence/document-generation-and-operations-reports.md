# SB-DI-009｜从材料生成结构化报告与行动清单

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 内容交付 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `draft` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证受控工程记录、发布说明或故障材料可被汇总为日报、周报、评审报告、整改任务和通知草稿，并保留事实来源。

## 用户目标与风险

用户需要将零散材料转成可执行交付物。风险是遗漏关键事项、把推断当事实、行动项不可追溯、格式不合规或文档无法打开。

## 受控输入与前置条件

私有夹具含合成材料、必备事实、禁止项、报告模板与行动项标准答案，并冻结版本和 SHA-256。需有隔离输出位置与文档生成能力。

## 产品路径

选择材料和交付模板；配置受众、输出格式与行动项规则；运行后查看报告、任务清单和来源摘要。

## 验收断言

- 指定事实、风险和待办被覆盖，禁止项未出现。
- 每项结论或行动项都可定位到受控材料；不确定内容被明确标记。
- 交付文档可打开，章节、表格和字段符合模板约束。
- 运行状态、失败原因与输出位置可见，临时资源可清理。

## 预期交付物、运行证据与变更影响

交付物为可预览报告和行动清单。证据包括事实覆盖、禁止项扫描、格式校验、来源抽样、阶段状态和清理记录。变更生成模型、模板、抽取规则或文件输出时必须重跑。

## 公开边界

不公开业务材料、报告正文、人员、组织、运行位置或原始日志。
