# SB-DI-003｜从文档提取信息并写入数据表

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 数据处理 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证从受控文档读取字段、按受控 Schema 提取、校验并写入隔离数据表的完整闭环。

## 用户目标与风险

用户希望把文档中的明确事实变成可查询记录。风险包括字段错位、重复写入、类型不匹配、无来源补造以及写入失败后仍显示成功。

## 受控输入与前置条件

私有夹具冻结合成文档、字段定义、目标表结构与标准记录，并记录版本和 SHA-256。需提供隔离目标表、可用提取模型和写入权限。

## 产品路径

选择文档输入与目标表；配置字段映射、缺失值策略和主键规则；保存并运行工作流；在运行详情和目标表核对记录。

## 验收断言

- 合法映射可运行；缺少必填字段、目标表或权限时有可定位提示。
- 提取结果符合字段类型、必填与唯一性规则。
- 标准答案中的每条记录恰好写入一次；无来源字段为空或按规则拒绝写入。
- 执行详情显示读取、提取、校验、写入的终态，输出能关联到输入和本次运行。
- 清理本 Case 创建的数据与临时资源。

## 预期交付物、运行证据与变更影响

交付物是可对账的数据表记录及执行摘要。`pass` 需保存夹具校验、行级对账、Schema 校验、阶段状态和清理记录。变更文档抽取、字段映射、写入器、权限或重试逻辑必须重跑。

## 公开边界

不公开任何业务文档、表数据、对象标识、环境、账号、内部任务或日志。
