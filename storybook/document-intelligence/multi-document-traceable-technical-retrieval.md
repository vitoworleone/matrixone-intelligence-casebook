# SB-DI-018｜多文档技术资料的可追溯检索与复核

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 知识检索 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `draft` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证一组相互关联的合成主报告、附件、检测记录、审阅意见和图件，可被跨文件解析、建立知识索引，并支持带来源的技术问答与人工复核。

## 用户目标与风险

用户要从长篇、多附件资料中核对范围、采样/检测事实、风险结论、审阅意见和修改记录。风险是只检索单一文件、跨文件关系断裂、表格/图件证据丢失、结论无来源或冲突内容被错误合并。

## 受控输入与前置条件

私有夹具为合成项目资料包、标准问题、事实/冲突清单和来源答案；文件、目录关系和答案均以版本与 SHA-256 冻结。需有隔离 Catalog、知识索引、问答入口和可写输出位置。

## 产品路径

导入受控资料包；解析正文、表格、扫描页与图件；建立知识索引；提交固定问题；在答案中打开来源并核对跨文件关联、冲突提示和人工复核标记。

## 验收断言

- 所有指定文件进入处理，解析失败或不支持内容在文件级明确提示。
- 标准问题的关键事实与人工答案一致，并可定位到文件、章节、页码、表格或图件上下文。
- 主报告、附件、记录、意见和修改说明的关系可被正确区分；冲突或无证据事实明确标为待核实。
- 检索不得把图件/扫描内容或模型推断当作未经证实的结论；索引和运行状态可追溯。
- 临时资料、索引与输出资源可清理。

## 预期交付物、运行证据与变更影响

交付物为带引文的问答结果、跨文件来源摘要和异常清单。`pass` 需保存夹具校验、文件覆盖、问答断言、来源抽样、冲突处理、阶段状态与清理记录。变更多文件解析、图表处理、索引、检索、引用或问答模型时必须重跑。

## 公开边界

不公开技术资料、图件、检测数据、地点、组织、人员、问题答案、环境、资源标识或日志。
