# SB-DI-016｜图像分析并输出结构化结果

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 图像理解 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `draft` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证合成图像可被分析为符合 Schema 的结构化结果，并能输出可复核的异常或分类结论。

## 用户目标与风险

用户要把图像信号转化为可处理记录。风险是误识别、无证据结论、字段格式不合规、未识别结果被掩盖。

## 受控输入与前置条件

私有夹具包含合成图像、标注答案、Schema 与禁止项，并以版本和 SHA-256 固定。需有可用图像分析能力和隔离输出位置。

## 产品路径

选择图像；配置分析字段、阈值和输出；运行后查看结构化结果、证据摘要与导出文件。

## 验收断言

- 输出通过 Schema，指定类别、区域或异常与标注答案一致。
- 不确定或未命中的结果明确标记，不得生成无来源事实。
- 输出可追溯到输入与运行，格式可下游消费；资源可清理。

## 预期交付物、运行证据与变更影响

交付物为结构化结果与证据摘要。证据包括夹具校验、字段比对、错误分类、输出校验和清理记录。变更图像模型、提示词、阈值、Schema 或输出时必须重跑。

## 公开边界

不公开图像、标注、模型配置、环境或日志。
