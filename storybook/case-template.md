# Storybook Case 模板

> 新建 Case 时复制本模板到对应领域目录，替换所有 `<...>` 占位符，并删除不适用的小节。设计原则、断言分层和门禁规则见 [测试方法论](testing-methodology.md)。

## 使用规则

- 一个文件只表达一个可解释的用户承诺；不要把多个无关能力拼成一个“大全 Case”。
- `required` 只用于发布时必须通过的关键承诺；没有自动化证据的 Case 不能标为已通过。
- 所有输入都必须是合成或已脱敏资料。不要写入真实环境地址、凭据、个人信息、资源 ID 或内部任务链接。
- 每个断言必须可判定，并能说明由什么证据支持；视觉、主观措辞等人工项需单独标注。
