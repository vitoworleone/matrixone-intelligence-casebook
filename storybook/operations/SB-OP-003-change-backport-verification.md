# SB-OP-003｜变更回迁完整性核查

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证基于授权代码协作证据核查变更回迁是否完整。

## 用户目标和风险

维护者需要确认目标版本是否包含所需变更。风险是只凭标题断言、遗漏依赖变更、把未证实状态写为完成或对仓库产生写操作。

## 受控输入与前置条件

私有夹具包含合成变更图、版本线、依赖关系和核查基准；代码协作连接仅可读。

## 产品路径

声明源与目标范围 → 收集受控证据 → 形成完整性矩阵 → 标记缺失与待确认项 → 人工结论。

## 明确验收断言

1. 每项完整性结论均有输入证据。
2. 直接变更、依赖变更和冲突分开报告。
3. 证据不足时返回待确认而非通过。
4. 不创建合并、提交或修改请求。

## 预期交付物、证据与变更影响

交付完整性矩阵、差异清单与待确认项。保留输入版本、引用与断言。协作连接、图谱规则或报告逻辑变更需重跑。

## 公开边界

不公开仓库、分支、变更、审查、人员或内部链接。
