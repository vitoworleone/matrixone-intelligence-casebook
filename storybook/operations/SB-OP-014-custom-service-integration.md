# SB-OP-014｜自定义服务发布与调用验证

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证自定义处理服务在隔离环境中的发布前契约检查、调用和错误处理。

## 用户目标和风险

集成者需要确认服务可被工作流安全调用。风险是接口不一致、权限绕过、重复副作用、泄露端点或在生产发布。

## 受控输入与前置条件

私有夹具包含模拟服务、请求响应契约、授权规则和故障情形；只允许隔离测试发布。

## 产品路径

校验服务契约与权限 → 发布至测试隔离区 → 发起受控调用 → 核验响应、错误和审计摘要 → 清理。

## 明确验收断言

1. 请求与响应均符合定义 Schema。
2. 未授权或无效请求被拒绝，且不产生副作用。
3. 错误可定位至验证、调用或响应阶段。
4. 测试资源在结束后按策略清理。

## 预期交付物、证据与变更影响

交付契约检查、调用结果和清理状态。保留服务版本、审计摘要与断言。接口、授权、运行时或工作流调用变更需重跑。

## 公开边界

不公开服务代码、端点、请求、令牌、环境或日志。
