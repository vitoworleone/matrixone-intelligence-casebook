# SB-OP-007｜CI 长日志失败分流

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从长运行日志中定位真实失败项、过滤噪声并给出分流建议。

## 用户目标和风险

维护者需要迅速定位可行动故障。风险是把警告当失败、遗漏第一个失败、泄露构建内容或不当自动重试。

## 受控输入与前置条件

私有夹具提供合成长日志、阶段边界、失败基准和噪声模式；环境不连接真实执行器。

## 产品路径

输入日志与范围 → 提取阶段和候选失败 → 归因到证据 → 输出优先级与下一步核查。

## 明确验收断言

1. 报告识别基准中的真实失败及其首次证据位置。
2. 警告、重试和级联错误与主失败分开。
3. 对不确定项标记待确认。
4. 不触发重跑、取消或修改流水线。

## 预期交付物、证据与变更影响

交付失败摘要、证据引用和分流建议。保留日志夹具版本和断言。解析、分类规则或模型变更需重跑。

## 公开边界

不公开真实日志、构建、项目、路径、凭据或执行地址。
