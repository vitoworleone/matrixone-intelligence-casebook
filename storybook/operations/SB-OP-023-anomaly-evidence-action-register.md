# SB-OP-023｜异常证据与后续动作登记

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证将零散异常忠实整理为预期、实际、证据、影响和后续动作登记表。

## 用户目标和风险

测试组织者需要把观察转成可复测的行动项。风险是混淆预期与实际、遗漏证据、重复分流或把推测作为已确认缺陷。

## 受控输入与前置条件

私有夹具提供合成异常观察、预期、证据片段、分类规则和行动基准；不连接真实任务系统。

## 产品路径

输入异常材料 → 提取预期与实际 → 关联最小证据 → 标记影响、分类和下一步 → 人工确认后再登记。

## 明确验收断言

1. 每条异常都有分开的预期、实际和证据字段。
2. 推测原因与已观察事实严格区分。
3. 重复异常按依据关联而非静默删除。
4. 不创建真实缺陷、任务或通知。

## 预期交付物、证据与变更影响

交付异常登记表、分类和后续动作草案。保留夹具、映射和断言。抽取、分类、模板或任务集成变更需重跑。

## 公开边界

不公开异常、日志、产品、人员、环境、问题或处理记录。
