# SB-OP-011｜配置变更风险与回滚清单

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证比较配置差异、识别风险并生成可审核回滚清单。

## 用户目标和风险

维护者需要在配置发布前理解影响。风险是遗漏关键差异、泄露敏感值、建议不可恢复修改或误把缺失项当默认值。

## 受控输入与前置条件

私有夹具提供合成前后配置、敏感字段规则、依赖关系和回滚基准；仅离线比较。

## 产品路径

提供两个受控版本 → 差异分类与脱敏 → 风险评估 → 生成回滚前置条件和核查项。

## 明确验收断言

1. 输出识别基准中的新增、删除和修改差异。
2. 敏感值被掩码，不出现在结果或证据中。
3. 每项风险说明影响假设与验证步骤。
4. 回滚清单不包含直接执行命令或无依据默认值。

## 预期交付物、证据与变更影响

交付差异摘要、风险清单和回滚草案。保留输入指纹、脱敏检查与断言。配置解析、掩码或风险规则变更需重跑。

## 公开边界

不公开真实配置、密钥、端点、环境、版本或变更记录。
