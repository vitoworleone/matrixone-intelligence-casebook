# SB-OP-001｜工作日失败汇总计划任务

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证按工作日计划汇总测试失败并生成待处理摘要的自动化任务。

## 用户目标和风险

维护者需要稳定获得失败概览。风险是漏报、重复投递、错误时区、把非失败事件混入或暴露内部日志。

## 受控输入与前置条件

私有夹具包含合成运行记录、日历、时区、过滤规则和投递目标；仅配置测试任务与测试渠道。

## 产品路径

配置计划、过滤条件和报告模板 → 手动预览 → 到点运行 → 校验摘要、幂等和失败处理。

## 明确验收断言

1. 仅汇总指定窗口内符合规则的失败项。
2. 报告包含时间窗口、归类、来源摘要和待确认项。
3. 同一计划窗口至多产生一份成功投递。
4. 任务失败显示失败阶段，不能静默成功。

## 预期交付物、证据与变更影响

交付计划定义、摘要和投递状态。保留触发记录、过滤结果和断言。调度器、时区、过滤或投递逻辑变更需重跑。

## 公开边界

不公开真实日志、任务、日历、接收目标或运行标识。
