# SB-OP-016｜模型服务迁移与回切条件

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证模型服务架构迁移方案中的依赖、验收门槛和回切条件。

## 用户目标和风险

平台团队需要避免迁移导致时延、可靠性或成本回退。风险是遗漏依赖、无阈值推进或缺乏可执行回切条件。

## 受控输入与前置条件

私有夹具提供合成现状、目标拓扑、SLO、演练结果和回切规则；不连接实际服务。

## 产品路径

输入方案与证据 → 识别前置条件和阶段门禁 → 生成迁移、观察和回切草案 → 人工审批。

## 明确验收断言

1. 每个阶段有进入、观察、退出和回切条件。
2. 未提供的容量或可靠性信息明确标记。
3. 建议不得绕过批准或直接改变生产流量。
4. 风险、证据和责任边界可独立核验。

## 预期交付物、证据与变更影响

交付阶段清单、门禁和回切草案。保留输入版本与断言。架构、SLO 或迁移流程变更需重跑。

## 公开边界

不公开拓扑、流量、SLO、环境、人员或演练记录。
