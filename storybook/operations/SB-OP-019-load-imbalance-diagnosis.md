# SB-OP-019｜负载不均诊断与验证实验

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从受控观测发现负载不均信号、形成假设并设计验证实验。

## 用户目标和风险

维护者需要先证实问题再选择修复。风险是误判根因、忽略反例或直接修改调度策略。

## 受控输入与前置条件

私有夹具提供合成负载、时序、容量和干扰因素；无生产观测或控制权限。

## 产品路径

输入观测 → 标记异常与反例 → 形成可证伪假设 → 设计低风险实验 → 人工确认。

## 明确验收断言

1. 观测事实、假设和实验预期分开。
2. 每个假设包含反证条件与所需数据。
3. 不将相关性宣称为根因。
4. 不执行重分配、扩容或配置变更。

## 预期交付物、证据与变更影响

交付诊断摘要、假设和实验计划。保留夹具和断言。指标、模型或诊断模板变更需重跑。

## 公开边界

不公开真实拓扑、指标、容量、任务、环境或日志。
