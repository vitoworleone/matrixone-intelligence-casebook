# SB-OP-008｜需求与契约驱动的 QA 验收包

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从产品需求和接口契约生成安全、可执行、可清理的 QA 验收包。

## 用户目标和风险

产品、研发和 QA 需要同一套可追溯验收描述。风险是虚构接口、字段或权限，或生成高风险清理动作。

## 受控输入与前置条件

私有夹具包含合成需求、接口契约、测试 Schema 和期望标准；只生成草案，不连接真实服务。

## 产品路径

输入需求与契约 → 提取范围 → 生成正常、异常、边界用例与清理方案 → 人工复核。

## 明确验收断言

1. 每条用例中的对象和字段均可回溯到输入。
2. 输出包含前置条件、步骤、预期、证据和清理动作。
3. 未知接口或权限明确隔离，不被编造。
4. 高风险删除或写入动作需要显式门禁，不能默认执行。

## 预期交付物、证据与变更影响

交付验收包、回归矩阵和清理草案。保留契约版本与断言。需求解析、契约模型或生成策略变更需重跑。

## 公开边界

不公开真实需求、接口、数据模型、测试脚本或内部验收记录。
