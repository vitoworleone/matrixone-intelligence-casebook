# SB-OP-012｜监控巡检报告定时投递

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从授权监控数据源读取指标、生成巡检报告并定时投递到授权协作渠道的闭环。

## 用户目标和风险

运维人员需要减少人工巡检。风险是错误数据窗口、阈值臆测、重复投递、目标误发和无法追踪失败。

## 受控输入与前置条件

私有夹具定义合成指标、阈值、计划、测试渠道、幂等键和回执基准；仅使用隔离连接。

## 产品路径

配置数据源、计划和目标 → 预览报告 → 到点读取数据并生成报告 → 投递 → 核验回执、重试和幂等。

## 明确验收断言

1. 报告包含数据窗口、指标、阈值判断、异常与缺失项。
2. 指标外的结论明确为未知，不能补造数据。
3. 同一窗口最多成功投递一次，失败可定位到阶段。
4. 仅向授权测试渠道发送，且投递前后状态可核验。

## 预期交付物、证据与变更影响

交付任务定义、报告预览、投递回执和运行状态。保留数据窗口、幂等和断言记录。监控连接、调度、模板或渠道变更需重跑。

## 公开边界

不公开监控地址、真实指标、群组、消息、任务标识或凭据。
