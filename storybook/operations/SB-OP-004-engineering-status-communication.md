# SB-OP-004｜工程记录到状态沟通材料

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证将工程记录与发布说明整理为日报、周报和灰度沟通草稿。

## 用户目标和风险

发布负责人需要一致、可追溯的状态材料。风险是夸大进度、泄露内部信息、遗漏风险或将草稿直接外发。

## 受控输入与前置条件

私有夹具提供合成工程记录、发布说明、受众规则和事实基准；运行不连接真实沟通渠道。

## 产品路径

输入受控材料 → 抽取事实与风险 → 生成不同受众的沟通草稿 → 逐项核验来源与未知项。

## 明确验收断言

1. 时间、状态和风险均可回溯到输入。
2. 未证实事项标记待确认，不被写成已完成。
3. 不同受众版本不得增加无来源事实。
4. 仅生成草稿，不能自动发送。

## 预期交付物、证据与变更影响

交付状态草稿、事实映射和待确认清单。保留夹具版本及断言。摘要、模板或授权策略变更需重跑。

## 公开边界

不公开工程记录、发布计划、受众、沟通内容或渠道。
