# SB-OP-021｜回归 Case 提交检查清单

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证为新回归 Case 生成并核查提交前清单。

## 用户目标和风险

维护者需要确保 Case 可复跑、可判定、可追溯。风险是把未执行 Case 标为通过、遗漏夹具或泄露运行信息。

## 受控输入与前置条件

私有夹具提供合成 Case 草稿、必填字段、证据规则和隐私政策；不提交至任务系统。

## 产品路径

输入 Case 草稿 → 校验元数据、夹具、断言、证据和公开边界 → 输出缺口清单 → 人工修订。

## 明确验收断言

1. 缺失受控输入、断言、证据或变更影响时明确报出。
2. `not run` 不可被视为通过。
3. 隐私风险被标记为阻塞项。
4. 不自动发布或修改 Case。

## 预期交付物、证据与变更影响

交付提交检查表和缺口报告。保留规则版本与断言。Case Schema、证据或隐私规则变更需重跑。

## 公开边界

不公开私有夹具、内部报告、人员、环境或审核记录。
