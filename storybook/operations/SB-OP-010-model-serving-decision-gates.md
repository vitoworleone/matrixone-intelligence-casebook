# SB-OP-010｜模型服务变更决策与回滚门禁

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证模型推理优化、迁移、量化、训练并行与调度策略的 Go/No-Go 分析合同。

## 用户目标和风险

平台团队需要基于受控实验数据评估收益、风险和回滚条件。风险是将模拟结果当成生产结论、遗漏容量或质量代价、自动推进高风险变更。

## 受控输入与前置条件

私有夹具提供合成基线、候选方案、约束、实验结果和回滚阈值；环境无变更执行权限。

## 产品路径

输入方案与证据 → 比较收益、风险、适用条件和回滚门槛 → 输出 Go/No-Go 草案 → 人工评审。

## 明确验收断言

1. 每项结论可回溯到输入实验或明确假设。
2. 输出包含收益、成本、风险、缺口和回滚条件。
3. 证据不足时不得给出通过结论。
4. 不修改模型服务、流量、容量或训练配置。

## 预期交付物、证据与变更影响

交付决策矩阵、实验缺口与回滚草案。保留夹具版本和断言。模型、基准、策略或模板变更需重跑。

## 公开边界

不公开模型规格、性能数据、容量、供应商、配置或实验记录。
