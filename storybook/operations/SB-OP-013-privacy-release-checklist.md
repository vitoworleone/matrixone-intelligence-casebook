# SB-OP-013｜公开材料隐私自检

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证对拟公开文字、表格和链接的隐私风险识别与发布前检查。

## 用户目标和风险

发布者需要在公开前发现身份、客户、环境、凭据或内部链接泄露。风险是漏检、过度自信或将建议替代人工合规决策。

## 受控输入与前置条件

私有夹具提供合成材料、敏感模式、允许公开项和判定基准；处理在隔离环境完成。

## 产品路径

提供公开草稿 → 执行模式与上下文检查 → 输出风险分级、证据位置和修订建议 → 人工复核。

## 明确验收断言

1. 识别夹具中规定的敏感类别并给出最小定位信息。
2. 允许公开的通用技术名称不被错误拦截为敏感信息。
3. 不能判断时标记待人工确认。
4. 不自动上传、删除或发布材料。

## 预期交付物、证据与变更影响

交付自检表、风险分级和修订建议。保留夹具版本、扫描摘要与断言。规则库、模型或发布流程变更需重跑。

## 公开边界

不公开待发布草稿、命中内容、真实个人资料、客户、环境或链接。
