# SB-OP-002｜周期提醒计划任务

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证周期性提醒的创建、触发、投递与停用。

## 用户目标和风险

使用者需要按规则收到提醒。风险是时区错位、重复提醒、在未授权渠道投递或无法停止任务。

## 受控输入与前置条件

私有夹具提供合成计划、测试时间、授权目标和幂等基准；只使用隔离测试渠道。

## 产品路径

配置周期、时区和目标 → 预览 → 触发 → 核验一次投递 → 停用并验证不再投递。

## 明确验收断言

1. 触发时间符合计划与时区。
2. 每个计划窗口最多投递一次。
3. 仅向授权测试目标投递。
4. 停用后不再产生消息，并保留状态记录。

## 预期交付物、证据与变更影响

交付计划、投递状态与停用记录。保留时间线与断言。调度、时区或渠道逻辑变更需重跑。

## 公开边界

不公开提醒内容、接收者、时间表或渠道凭据。
