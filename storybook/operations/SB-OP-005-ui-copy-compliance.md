# SB-OP-005｜用户可见文案合规审查

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证根据规范审查用户可见文案与错误提示。

## 用户目标和风险

产品团队需要发现不一致、误导或不可访问的文案。风险是模型将偏好伪装成规范、遗漏关键错误边界或直接改写产品内容。

## 受控输入与前置条件

私有夹具提供合成界面文本、规范、场景与判定基准；助手仅审查、不写入产品。

## 产品路径

输入文本与规范 → 逐项比对 → 输出问题、规范引用和建议草案 → 人工审阅。

## 明确验收断言

1. 每项问题引用给定规范或输入文本。
2. 区分违反规范、建议优化和待确认项。
3. 不虚构不存在的页面、功能或规则。
4. 不直接修改页面或发布文案。

## 预期交付物、证据与变更影响

交付审查清单和修订建议。保留规范版本与断言。规范、提示词或文案解析变更需重跑。

## 公开边界

不公开真实界面、设计稿、规范全文或内部评审。
