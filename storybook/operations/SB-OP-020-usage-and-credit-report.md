# SB-OP-020｜处理配置与用量报告

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从受控处理记录汇总运行配置、用量和费用单位。

## 用户目标和风险

维护者需要可核对的用量说明。风险是遗漏记录、错误聚合、暴露价格或把预估成本写成结算事实。

## 受控输入与前置条件

私有夹具提供合成运行记录、计量规则和聚合基准；不连接真实账单或资源系统。

## 产品路径

输入运行摘要与规则 → 汇总配置与用量 → 标记缺失项和计算依据 → 人工复核。

## 明确验收断言

1. 聚合值可追溯到夹具记录和计量规则。
2. 实际值、预估值和未知项清楚区分。
3. 敏感配置和值按策略掩码。
4. 不修改账单、配额或运行任务。

## 预期交付物、证据与变更影响

交付用量报告、计算依据和异常项。保留夹具与断言。计量规则、聚合或掩码策略变更需重跑。

## 公开边界

不公开真实用量、价格、账单、配置、项目或环境。
