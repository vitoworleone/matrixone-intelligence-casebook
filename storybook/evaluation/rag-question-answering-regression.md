# SB-EV-001｜RAG 知识问答回归评测

|---|---|

| Case 类型 | 端到端评测回归 |
| 内容状态 | `ready` |

| 当前运行结果 | `not run` |

## 覆盖范围

验证在冻结数据、模型、提示词、检索配置和评分口径下，RAG 能完成入库、检索、回答、引用与拒答，并输出逐题证据和可比较指标。

## 用户目标与风险

评测人员需要发现版本更新导致的检索或回答退化。风险是只看平均分、混用数据/模型版本、把历史结果当作当前通过，或不能定位到具体问题。

## 受控输入

私有夹具冻结合成文档、问题、标准答案、预期证据、拒答问题、Judge/聚合器版本和 SHA-256。公开仓库不保存题目、答案或分数。

## 前置条件

- 入库、嵌入、检索、问答与评分能力可用；
- 本次运行的版本、配置和模型身份可记录；
- 存在隔离索引及结果账本位置。

## 产品路径

1. 校验冻结夹具和配置。
2. 入库并建立索引。
3. 逐题执行检索与回答，记录候选证据、答案、状态与延迟。
4. 使用冻结口径计算检索、回答、证据支持和拒答结果。
5. 与兼容基线比较并输出逐题差异。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 每题都有明确终态；超时和错误不可被静默排除。 |
| A02 | 应答题的答案与证据满足冻结的逐题判定规则。 |
| A03 | 拒答题不输出无来源结论。 |
| A04 | 评分只使用本次冻结夹具、Judge 与聚合口径。 |
| A05 | 任一 required 题失败即该 Case 失败，均分不能覆盖。 |
| A06 | 输出可定位数据/模型/配置/题目版本与逐题证据。 |

## 预期交付物

脱敏的运行账本、逐题状态与判定、聚合指标、相对基线差异和失败分类。

## 运行证据

夹具/配置/模型版本、入库摘要、逐题结果、评分器版本、基线可比性检查和清理记录。

## 变更影响

解析、切分、嵌入、检索、模型、提示词、引用、拒答、评分器或聚合口径变更时必须重跑。

## 公开边界

不公开题库、标准答案、模型密钥、环境、逐题原始输出、历史分数或内部报告。
