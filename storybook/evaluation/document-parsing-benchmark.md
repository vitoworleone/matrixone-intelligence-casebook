# SB-EV-004｜多类型文档解析质量评测

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 质量评测 |
| Case 类型 | 端到端评测回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证当前产品配置在冻结的公开许可或合成文档集上，能够输出可评分的解析结果，并以固定评分工具评估文本、版面、表格、公式、图像及阅读顺序等质量维度。

## 用户目标与风险

产品团队需要知道当前版本的解析质量是否退化。风险是沿用旧环境结果、只评成功文档、用不可比配置进行对比，或将历史分数称为当前通过。

## 受控输入

私有夹具冻结多格式文档、页面清单、Golden、评分器版本和 SHA-256。公开仓库不包含文档、Golden 或结果分数。

## 前置条件

- 当前解析工作流可导出逐文档结果及阶段状态；
- 评分器输入适配和评分规则已冻结；
- 运行时配置、模型与开关可记录。

## 产品路径

1. 校验夹具和评分器版本。
2. 以当前推荐配置运行解析工作流，先 Smoke 后批量。
3. 导出成功、失败、重试和超时的逐文档结果。
4. 转换输出并运行固定评分器。
5. 与可比基线比较并归类失败样本。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 所有冻结文档都有明确结果或失败状态，不可跳过失败页。 |
| A02 | 输出格式满足评分器输入合同。 |
| A03 | 每个质量维度按冻结评分规则计算并可定位到文档/页级。 |
| A04 | 对比只在数据、评分器和配置可比时进行。 |
| A05 | required 阈值或关键类别失败使 Case 失败，不用总体均分掩盖。 |
| A06 | 本次配置与运行版本可追溯。 |

## 预期交付物

逐文档状态、维度级分数、可比性声明、退化摘要和失败类别。

## 运行证据

夹具/Golden/评分器校验、配置摘要、逐文档终态、评分输出、可比性检查和清理记录。

## 变更影响

解析器、OCR、布局/表格/公式处理、模型、配置、输出适配或评分器变更时必须重跑。

## 公开边界

不公开文档集、Golden、模型配置、环境、逐页输出、历史对比对象或原始日志。
