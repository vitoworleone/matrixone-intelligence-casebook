# SB-EV-002｜知识问答基准构建与执行

| 字段 | 值 |
|---|---|
| 产品域 | 知识库 / 质量评测 |
| Case 类型 | 端到端评测回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证评测人员可从受控知识资料构建带来源、标准答案和评分规则的问题基准，并在实际问答入口执行、评分和形成可复查结论。

## 用户目标与风险

团队需要把“知识库似乎可用”转化为可重复的验收。风险是问题没有来源、评分标准不一致、只挑容易问题，或把候选问题误作已验证结果。

## 受控输入

私有夹具冻结两类合成资料、单资料与跨资料问题分层、标准答案、来源映射和评分量表；只暴露版本与 SHA-256。

## 前置条件

- 资料已绑定到隔离知识资产；
- 问题生成/审核规则和评分量表已冻结；
- 有保存逐题答案与引用的受控账本。

## 产品路径

1. 从受控资料生成候选问题并检查覆盖层级。
2. 审核问题、标准答案、来源与评分规则后冻结基准。
3. 在实际问答入口逐题执行。
4. 记录回答、引用、评分和失败原因。
5. 汇总结果并输出待优化问题类别。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 每题都有唯一题目版本、预期来源和评分规则。 |
| A02 | 基准同时覆盖单资料、跨资料、查找、比较和受限回答问题。 |
| A03 | 实际回答与引用被逐题保存并可重新评分。 |
| A04 | 评分不能把无引用或无来源回答判为完全正确。 |
| A05 | 未执行题、错误题和人工复核题必须显式计入账本。 |
| A06 | 题库和产物清理遵循受控数据保留策略。 |

## 预期交付物

冻结问题基准、逐题执行与评分账本、类别级总结和待处理项。

## 运行证据

夹具校验、题目/来源/量表完整性、逐题运行、评分一致性、异常分类和清理记录。

## 变更影响

知识入库、问答入口、问题生成、引用、评分量表或结果导出变更时必须重跑。

## 公开边界

不公开资料、题目、答案、评分细节、评测人员、模型配置或运行记录。
