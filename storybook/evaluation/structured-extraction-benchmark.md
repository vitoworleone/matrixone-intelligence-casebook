# SB-EV-005｜Schema 驱动的结构化提取质量评测

| 字段 | 值 |
|---|---|
| 产品域 | 文档智能 / 信息提取评测 |
| Case 类型 | 端到端评测回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统对冻结的多类文档和预定义 Schema 进行字段提取，导出结构化结果，并按数据集、字段和总体三个层次与 Golden 对账。

## 用户目标与风险

团队需要以可重复口径比较版本的提取能力。风险是 Schema 不一致、只报告总体结果、忽略字段错误、从来源外补造信息或将旧结果继承为新版本通过。

## 受控输入

私有夹具冻结合成或许可公开文档、Schema、Golden、字段级权重、空值规则和 SHA-256。公开文档仅描述治理规则。

## 前置条件

- 每类夹具有经过核对的 Schema 与 Golden；
- 当前提取工作流可导出逐文档 JSON 与失败状态；
- 字段归一化和评分器版本固定。

## 产品路径

1. 校验夹具、Schema、Golden 与评分器。
2. 对每类资料先 Smoke，再进行完整批次提取。
3. 导出 JSON、阶段状态和失败原因。
4. 按字段类型和空值规则对比 Golden。
5. 输出数据集级、字段级、总体结果及退化分析。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 输出 JSON 均符合对应 Schema 或有明确失败状态。 |
| A02 | 所有文档参与统计；失败样本不可静默删除。 |
| A03 | 字段级结果按冻结规则与 Golden 一致计算。 |
| A04 | 无来源字段遵守空值规则，不将臆造值判为正确。 |
| A05 | required 字段或数据集未达门槛即 Case 失败。 |
| A06 | 新旧结果仅在夹具、Schema 和评分器相同或明确映射时比较。 |

## 预期交付物

逐文档状态、字段级判定、数据集级汇总、总体质量和可解释的失败分类。

## 运行证据

夹具/Schema/Golden/评分器版本、JSON 校验、字段对账、阈值判定、基线可比性与清理记录。

## 变更影响

解析、提取模型、提示词、Schema、空值策略、归一化或评分逻辑变更时必须重跑。

## 公开边界

不公开文档、Schema 明细、Golden、字段值、模型、分数、环境或原始运行日志。
