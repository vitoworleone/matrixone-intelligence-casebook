# SB-EV-006｜有来源的训练与评测数据集生成

| 字段 | 值 |
|---|---|
| 产品域 | 数据集生成 / 质量评测 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统能从受控资料和明确规则生成结构化训练或评测样本，保留来源、满足输出 Schema，并拒绝材料外的“看似合理”内容。

## 用户目标与风险

AI 运营人员需要可用于后续训练/评测的数据集。风险是样本失去来源、格式不可用、数量误报、重复严重或产生无依据事实。

## 受控输入

私有夹具冻结合成资料、生成目的、样本数量、输出 Schema、允许主题、禁止项、标准来源映射和 SHA-256。

## 前置条件

- 输入资料和输出位置均隔离；
- 生成模型与规则版本可记录；
- Schema 校验、重复检查和来源核对工具可用。

## 产品路径

1. 在数据集生成入口选择受控资料与用途。
2. 配置样本格式、数量、规则和 Schema。
3. 显式要求每条样本保留来源并禁止来源外事实。
4. 运行生成、保存和校验。
5. 对输出进行 Schema、数量、去重、来源与事实支持检查。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 每条样本符合冻结 Schema，包含用途与来源字段。 |
| A02 | 样本数符合配置或有明确失败/不足状态。 |
| A03 | 每条答案/标签能关联至至少一个受控来源。 |
| A04 | 来源外断言、无法支持的样本或严重重复被拒绝或标记。 |
| A05 | 生成用途、规则、模型与版本在运行账本中可追溯。 |
| A06 | 临时数据集与资源按照保留策略清理。 |

## 预期交付物

符合 Schema 的受控数据集、来源映射、质量检查结果及异常项。

## 运行证据

夹具校验、配置摘要、Schema/数量/去重/来源检查、异常分类和清理记录。

## 变更影响

数据集模板、生成模型、提示词、规则、Schema、来源追溯或质量检查变更时必须重跑。

## 公开边界

不公开输入资料、生成样本、标准答案、模型配置、资源名称、人员或运行日志。
