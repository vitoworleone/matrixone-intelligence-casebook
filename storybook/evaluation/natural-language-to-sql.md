# SB-EV-003｜自然语言到 SQL 的执行正确性评测

| 字段 | 值 |
|---|---|
| 产品域 | Explore / NL2SQL / 质量评测 |
| Case 类型 | 端到端评测回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统面对冻结的公开或合成结构化问题集时，能发现相关 Schema、生成并安全执行查询、依据结果回答，并以确定性执行结果判定正确性。

## 用户目标与风险

评测人员需要衡量自然语言问数的真实可用性。风险是仅比较生成 SQL 文本、忽略执行失败、让模型使用未授权表，或把评分边界问题自动掩盖。

## 受控输入

私有夹具冻结合成或许可公开数据快照、Schema、问题、标准执行结果、SQL 安全策略及 SHA-256；公开文档不存 SQL、查询或结果。

## 前置条件

- 隔离数据库已按快照创建；
- 执行身份仅有只读最小权限；
- 查询超时、行数上限和危险语句拒绝策略已冻结。

## 产品路径

1. 校验数据快照和 Schema 版本。
2. 在受控问数入口逐题提交自然语言问题。
3. 记录生成查询、执行状态、结果摘要、回答、延迟与错误。
4. 将实际结果与标准执行结果比较，并对边界题人工复核。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 每题查询仅访问白名单 Schema，危险或越权操作被拒绝。 |
| A02 | 可执行题的结果与冻结标准结果一致。 |
| A03 | 回答不得与实际执行结果矛盾。 |
| A04 | 语法、权限、超时和空结果均有可区分状态。 |
| A05 | 边界题经规则或人工复核，不能仅由平均分决定。 |
| A06 | 本 Case 不保留可写数据或查询副作用。 |

## 预期交付物

逐题执行账本、结果正确性、查询安全状态、回答一致性和指标摘要。

## 运行证据

快照校验、Schema 版本、逐题执行摘要、结果对账、安全拒绝测试、人工复核和清理记录。

## 变更影响

语义解析、Schema 检索、SQL 生成、执行器、权限、结果解释、模型或评分口径变更时必须重跑。

## 公开边界

不公开数据快照、SQL、题目、结果、连接信息、模型、用户或内部评测报告。
