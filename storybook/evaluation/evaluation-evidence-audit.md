# SB-EV-007｜评测证据审计与可发布结论

| 字段 | 值 |
|---|---|
| 产品域 | 质量治理 / 评测证据 |
| Case 类型 | 产品质量回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统可将一次受控评测的输入版本、配置、逐项结果、聚合口径和失败项组织为可审计证据，并据此生成不会夸大结论的摘要。

## 用户目标与风险

质量负责人需要判断一份评测结论是否可用于版本决策。风险是遗漏失败项、把不可比结果横向比较、将历史结果称为当前结果，或让摘要把“未运行”写成“通过”。

## 受控输入

私有夹具提供合成的评测运行账本、包含通过/失败/阻塞/未运行项的结果集、冻结的版本元数据和审核规则；公开仓库不保存结果内容或分数。

## 前置条件

- 每项运行结果都有可解析状态和关联版本；
- 审计规则明确 required Case、可比性条件和结论措辞；
- 输出摘要可关联至受控证据账本。

## 产品路径

1. 导入受控评测账本和审计规则。
2. 校验输入/模型/配置/评分器的版本完整性。
3. 聚合逐项状态，检查 required Case 与可比性。
4. 生成管理摘要和待处理项。
5. 审核摘要中每条结论均能回到证据账本。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 每项结果被保留为 pass、fail、blocked 或 not run 之一。 |
| A02 | 任一 required 的 fail、blocked 或 not run 阻止“可接受/通过”结论。 |
| A03 | 缺少数据、模型、配置或评分版本的结果被标为不可审计。 |
| A04 | 不可比基线不会被写为性能提升或退化。 |
| A05 | 摘要区分已观察结果、历史参考和待验证假设。 |
| A06 | 摘要中的结论、计数和待处理项可回溯至受控账本。 |

## 预期交付物

一份包含质量状态、证据完整性、可比性声明、风险和后续动作的审计摘要。

## 运行证据

输入账本校验、状态聚合、required 门禁判断、可比性检查、摘要到证据的追溯结果和清理记录。

## 变更影响

评测账本格式、状态语义、门禁规则、基线比较规则、摘要模板或证据链接逻辑变更时必须重跑。

## 公开边界

不公开真实评测账本、分数、失败内容、项目、人员、环境、模型配置或内部报告。
