# SB-DK-010｜检索方案的可证伪选型

| 字段 | 值 |
|---|---|
| 产品域 | 知识库规划 / 检索 |
| Case 类型 | 产品决策回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统能基于已给定的目标、时间、约束和合成资料，生成可执行的知识库计划与可证伪的关键词/向量/混合检索对比方案；它不把一般性建议表述为已经验证的结论。

## 用户目标与风险

实施人员需要在有限周期内制定知识库试点计划和选型实验。风险是将假设写成事实、没有可验收任务、忽略数据/权限/质量前提，或以泛化陈述替代实验。

## 受控输入

私有夹具冻结目标说明、团队容量、可用资料属性、技术约束及选型评审表；不公开真实项目计划或人员信息。

## 前置条件

- 目标、约束和完成定义已被结构化输入；
- 检索候选方案与对比维度已冻结；
- 输出计划可被人工或规则校验。

## 产品路径

1. 输入受控目标、时间约束和资料特征。
2. 生成任务拆分、交付物和验收清单。
3. 生成检索候选方案及其适用假设。
4. 将每项假设映射到可执行的实验、指标和决策规则。
5. 审核并导出计划。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 输出包含可分派任务、交付物、依赖与明确完成条件。 |
| A02 | 每个检索结论明确标记为已知约束、一般建议或待验证假设。 |
| A03 | 每个待验证假设均有对应夹具、比较方法、指标和 Go/No-Go 规则。 |
| A04 | 计划不虚构数据规模、性能结果、人员承诺或已完成验证。 |
| A05 | 输出可导出并保留输入约束与版本关联。 |

## 预期交付物

一份可执行的试点计划和检索选型实验表，清楚区分事实、假设和后续验证。

## 运行证据

输入版本、约束覆盖检查、任务/实验映射、假设标签检查、导出验证和人工复核记录。

## 变更影响

计划生成、知识库配置、检索策略、评测口径或导出能力变更时必须重跑。

## 公开边界

不公开真实项目、组织、人员、时间表、资料或内部决策记录。
