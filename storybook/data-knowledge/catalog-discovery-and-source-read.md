## 覆盖范围

验证用户能在授权范围内列出 Catalog 对象、取得稳定的分页结果、生成文件集合清单，并将一个已登记的数据源交给下游处理。它控制“列表看似成功但遗漏对象、越权读取、清单与实际不一致”的风险。

## 用户目标与风险

数据人员需要可靠地发现可用资料，并把正确的数据源传给后续工作流；系统不得猜测路径、混入不可访问对象或把分页边界当成完整结果。

## 受控输入

私有夹具冻结一组具有多页列表、嵌套目录、文件元数据和一个可读取数据源的合成 Catalog。执行器只记录夹具版本、对象计数与 SHA-256，不将文件或名称提交到公开仓库。

## 前置条件

- 使用隔离运行空间及最小读取权限；
- 输入 Catalog 已完成登记，且包含足以触发分页的对象数；
- 有可观察的下游消费节点和临时输出位置。

## 产品路径

1. 打开或创建数据处理工作流。
2. 配置 Catalog 列表、文件清单和数据源读取能力，连接上下游。
3. 运行并检查每个阶段的终态、分页游标和输出摘要。
4. 由下游节点消费读取结果，核对清单与实际读取对象。
5. 清理本次临时输出。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 列表仅返回当前身份可访问的对象，且分页合并后无重复、无遗漏。 |
| A02 | 文件清单包含夹具定义的每个目标对象及其可核对元数据。 |
| A03 | 读取能力只接受已登记且被授权的数据源；无效或未授权输入有明确失败原因。 |
| A04 | 下游收到的对象集合与清单一致，不发生静默截断或替换。 |
| A05 | 任一阶段失败时，运行详情能定位到阶段及失败原因。 |
| A06 | 临时产物和运行资源可清理；清理失败按失败或阻塞记录。 |

## 预期交付物

一个可核对的对象列表、文件清单和供下游消费的受控读取结果，均带本次运行关联信息，不暴露底层连接配置。

## 运行证据

夹具版本与校验、分页合并计数、清单比对、授权拒绝测试、下游消费摘要、阶段终态与清理记录。当前 `not run` 不代表通过。

## 变更影响

Catalog 权限、分页、对象元数据、数据源登记、工作流节点契约或清理逻辑变更时必须重跑。

## 公开边界

不公开真实目录、对象名、连接信息、身份、资源标识、执行日志或内部任务关联。
