# SB-DK-004｜结构化数据问答与结果追溯

| 字段 | 值 |

| 当前运行结果 | `not run` |

## 覆盖范围

验证用户可对合成 CSV 或数据表完成分组、聚合、Top-N、重复检测、缺失字段判断和受控自然语言问数，并得到能关联查询结果的结论。

## 用户目标与风险

业务用户希望不写 SQL 也能得到正确统计。风险是错误选择数据范围、口径不一致、结果无法核对，或对缺失信息给出编造答案。

## 受控输入

私有夹具冻结一份小型合成结构化数据、问题集、确定性标准结果和版本哈希；不公开字段值、问句或金标准明细。

## 前置条件

- 合成表已导入隔离数据范围；
- 当前身份仅能访问该表；
- 统计口径、排序规则和空值规则已冻结。

## 产品路径

1. 在问数入口选择受控数据范围。
2. 依次提交冻结的统计和检查类问题。
3. 查看自然语言结论、必要明细/汇总及可追溯的查询结果。
4. 将结果与标准答案自动对账。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 每个问题只使用选定数据范围。 |
| A02 | 分组、聚合、Top-N 和重复检测与标准结果一致。 |
| A03 | 对缺失字段或无结果问题明确说明限制，不补造数值。 |
| A04 | 结果包含足以核对的聚合/明细或等价查询证据。 |
| A05 | 无法执行的请求保留失败原因，不能展示无依据结论。 |
| A06 | 完成后不保留本 Case 临时数据或访问授权。 |

## 预期交付物

逐题可核对的回答、结果摘要和受控查询证据；无结果与拒答均有明确状态。

## 运行证据

夹具版本、逐题输入标识、确定性结果比对、数据范围检查、查询追溯摘要、错误与清理记录。

## 变更影响

问数规划、SQL/计算执行、语义层、结果呈现、权限和空值逻辑变更时必须重跑。

## 公开边界

不公开真实经营口径、数据表、查询文本、SQL、人员、客户或运行日志。
