# SB-DK-009｜知识资产盘点与引用边界

| 字段 | 值 |
|---|---|
| 产品域 | 知识库治理 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统能识别当前会话实际绑定的知识资产，按冻结规则盘点其中的对象并按原始来源归组，同时避免把“可用列表”或未绑定资料误作本次上下文。

## 用户目标与风险

运营人员需要在评测前确认知识库中有哪些内容。风险是 Agent 猜测当前知识库、对象计数不稳定、来源归组错误或泄露未授权资产。

## 受控输入

私有夹具冻结一个多来源合成知识库、对象/来源映射和期望统计；只记录夹具版本及 SHA-256。

## 前置条件

- 当前会话仅绑定一个隔离知识资产；
- 夹具包含可按来源归组的多类对象；
- 会话绑定状态可观察。

## 产品路径

1. 绑定受控知识资产。
2. 请求系统确认当前绑定范围并输出对象盘点。
3. 按冻结规则对对象和来源归组。
4. 与预期映射比对，并尝试访问一个未绑定资产以验证边界。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 系统明确识别当前绑定资产，而非从全量可用资产猜测。 |
| A02 | 对象数量、来源数量和映射与冻结标准一致。 |
| A03 | 归组规则可解释，不能把不同来源错误合并。 |
| A04 | 未绑定资产不会出现在盘点或引用中。 |
| A05 | 无法读取时给出限制说明，不返回推测统计。 |

## 预期交付物

一份可核对的受控知识资产盘点摘要及对象到来源的映射说明。

## 运行证据

绑定摘要、对象/来源计数比对、边界访问测试、失败信息和清理记录。

## 变更影响

知识绑定、资产列表、媒体/文档索引、来源归组、会话上下文或权限变更时必须重跑。

## 公开边界

不公开知识库名、文件名、对象映射、会话身份、资源 ID 或原始对话。
