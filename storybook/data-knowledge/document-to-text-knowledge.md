# SB-DK-005｜文档到可检索文本知识

| 字段 | 值 |
|---|---|
| 产品域 | 知识库 / 文档处理 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证从受控 Catalog 文档到解析、切分、文本索引、Catalog 产物、检索问答和来源追溯的闭环；同时验证自然语言生成的候选工作流在用户确认前不会被自动保存或运行。

## 用户目标与风险

非技术用户希望将资料变为可检索知识。风险是生成的流程与实际参数不一致、文件解析后无法检索、回答失去来源，或未经确认就触发运行。

## 受控输入

私有夹具为合成的多格式文档、固定事实问题、预期片段和夹具哈希；公开页面不保存文档、提示词或检索结果。

## 前置条件

- 有隔离 Catalog、输出位置和文本知识索引；
- 解析和嵌入能力可用；
- 文档范围、切分策略和运行参数均可观察。

## 产品路径

1. 将合成文档放入受控 Catalog。
2. 选择文档知识准备模板，或用自然语言生成候选工作流。
3. 核对数据绑定、参数和工作流拓扑后再显式保存运行。
4. 检查解析、切分、索引、写入和追溯阶段。
5. 用冻结问题检索并核对回答与来源。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 候选工作流的画布、参数与可执行定义保持一致。 |
| A02 | 未经显式确认不保存、不运行、不产生写入。 |
| A03 | 成功运行产生可检索的文本片段和可追溯产物。 |
| A04 | 冻结事实问题命中正确片段并显示来源。 |
| A05 | 不可解析文件或无权限输入有可定位失败，不产生伪索引。 |
| A06 | 临时知识和输出可被清理。 |

## 预期交付物

可检索文本知识、解析与索引摘要、问题回答及来源关联。

## 运行证据

夹具校验、候选/已确认状态、运行参数摘要、阶段终态、检索引用比对与清理记录。

## 变更影响

文档解析、切分、嵌入、知识索引、自然语言工作流生成、确认交互或血缘变更时必须重跑。

## 公开边界

不公开文档内容、模型配置、工作流定义、资源名、环境或内部任务记录。
