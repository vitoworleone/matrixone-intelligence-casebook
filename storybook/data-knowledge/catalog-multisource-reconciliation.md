# SB-DK-002｜Catalog 多来源材料核对与可追溯交付

| 字段 | 值 |
|---|---|
| 产品域 | Catalog / 文档与数据协作 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证系统能从受控 Catalog 中读取索引、压缩包、正文、附件和正式文档，提取同一业务字段的事实、识别一致/差异/缺失/冲突，并生成可预览的比较报告。

## 用户目标与风险

资料核对人员需要一个能说明每项结论来自哪里的交付物。主要风险是访问失败后继续编造结论、只比较部分来源、或者报告无法回溯原始材料。

## 受控输入

私有夹具提供相互关联的合成索引、压缩包和多格式资料，并冻结标准差异表与夹具哈希。公开文档只保留夹具版本规则。

## 前置条件

- 本次执行具备全部夹具的读取权限和报告写入位置；
- 资料索引定义了比较字段与来源关联规则；
- 报告生成能力可用。

## 产品路径

1. 在 Catalog 指定资料集合与比较字段。
2. 读取索引并展开受控归档内容。
3. 提取正文、附件与文档中的候选事实，按来源比对。
4. 生成并预览比较报告。
5. 核对报告中的来源定位、差异分类及输出文件。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 所有夹具来源被纳入或被明确标记为不可读；不得静默跳过。 |
| A02 | 每个比较字段的结论属于一致、差异、缺失或冲突之一。 |
| A03 | 标准差异表中的事实和分类与报告逐项一致。 |
| A04 | 每条结论可关联回至少一个合成来源及位置描述。 |
| A05 | 读取、解压或生成失败时不生成伪完整报告，并给出可定位原因。 |
| A06 | 导出报告可预览且内容与页面摘要一致。 |

## 预期交付物

一份包含核对范围、字段级结论、来源引用、未决项和生成时间的可预览报告。

## 运行证据

夹具校验、来源处理清单、字段级比对、报告预览校验、失败分类与清理记录。

## 变更影响

Catalog 访问、压缩包处理、文档解析、事实比对、报告导出或引用渲染变更时必须重跑。

## 公开边界

不公开任何业务材料、文件名、比较结论、人员、组织、环境地址或原始报告。
