# SB-DK-007｜音视频转录入库与可追溯问答

| 字段 | 值 |
|---|---|
| 产品域 | 多媒体知识库 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证受控音频或视频的音轨转录、文本切分、知识索引、派生产物保存和基于口播内容的可追溯问答。视觉理解不属于本 Case 的通过范围。

## 用户目标与风险

知识运营人员希望把培训或服务录音变为可查询资料。风险是任务完成但转录错误、问答无来源、把未覆盖的画面理解误报为已验证能力。

## 受控输入

私有夹具含有授权的合成语音/视频、人工校对文本、固定问题和来源片段映射；只在私有执行器记录版本和 SHA-256。

## 前置条件

- 媒体读取、音轨处理、语音转写与文本索引可用；
- 目标知识库和临时输出位置已隔离；
- 转录语言与噪声处理策略已冻结。

## 产品路径

1. 在 Catalog 选择受控音频或视频。
2. 选择媒体转录入库能力并配置语言、知识库与输出。
3. 运行媒体读取、转写、切分、索引、保存阶段。
4. 在知识问答入口提交冻结问题。
5. 对照人工校对文本检查回答与引用。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 音频和视频输入均可进入明确终态。 |
| A02 | 冻结的关键口播事实在转录文本中可定位。 |
| A03 | 固定问题回答正确，并引用正确的转录片段。 |
| A04 | 系统不把视频画面内容当作本 Case 已验证的事实来源。 |
| A05 | 失败时区分媒体读取、转写、索引和问答阶段。 |
| A06 | 转录、索引和临时文件均可清理。 |

## 预期交付物

可检索的转录知识、派生转录交付物、带来源的口播事实回答。

## 运行证据

夹具校验、转录对照摘要、阶段终态、逐题引用比对、能力边界确认和清理记录。

## 变更影响

媒体路由、ASR、切分、嵌入、知识问答、产物保存或引用逻辑变更时必须重跑。

## 公开边界

不公开音视频、转写文本、问句、模型、资源名、运行日志或身份信息。
