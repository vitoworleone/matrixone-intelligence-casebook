# SB-DK-006｜图文双索引与来源定位

| 字段 | 值 |
|---|---|
| 产品域 | 多模态知识库 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证含正文与图像的合成资料经解析后，文本索引和图片索引均可建立、可查询且能回到正确页/对象；覆盖一般图文资料和工程图纸类资料的共同回归合同。

## 用户目标与风险

资料维护人员需要同时查找文字事实和视觉主题。风险是只建立单一索引、图像与页面错配、视觉命中无法追溯，或把图像中没有的信息作为事实回答。

## 受控输入

私有夹具含有可区分的文本事实、页面图像、内嵌图像与工程示意图，并冻结问题集、页级预期映射和 SHA-256。

## 前置条件

- 多模态解析及文本/图片嵌入能力均可用；
- 有独立文本和图片索引配置；
- 输入、输出和索引均在隔离范围。

## 产品路径

1. 在 Catalog 选择图文资料。
2. 选择图文知识准备或图纸解析能力并配置双索引。
3. 运行解析、派生视觉对象、文本/图片索引和保存阶段。
4. 分别提交文字事实和视觉主题检索问题。
5. 核对命中对象、页级引用和原始资料关联。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 文本与图片索引均有明确创建终态。 |
| A02 | 文本问题命中冻结的文字来源；视觉问题命中冻结的图像或页面来源。 |
| A03 | 每个结果可关联到正确的原始资料与页/对象位置。 |
| A04 | 缺少图片索引或视觉能力时，系统明确降级/失败而非伪造视觉结果。 |
| A05 | 图像与文本的追溯关系不会交叉错配。 |
| A06 | 临时派生对象、索引及运行资源可清理。 |

## 预期交付物

双索引知识资产、可区分的文本和视觉检索结果、页级或对象级来源引用。

## 运行证据

夹具版本、双索引创建摘要、逐题命中映射、来源校验、降级行为和清理记录。

## 变更影响

视觉解析、图像派生、图片/文本嵌入、检索融合、引用渲染和权限变更时必须重跑。

## 公开边界

不公开图纸、图片、文档、索引配置、模型、资源标识或真实检索输出。
