# SB-DK-012｜连接器接入、处理与追溯

| 字段 | 值 |
|---|---|
| 产品域 | 数据连接 / 处理 / 治理 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证受控外部数据通过连接器或文件接入进入 Catalog/数据表，经过处理后可被下游使用，且输入、派生产物、输出与运行之间保持可核对追溯。

## 用户目标与风险

数据工程人员需要稳定接入一批资料并支持后续查询/分析。风险是连接授权泄露、增量重复或遗漏、数据处理完成却无法说明来源和影响范围。

## 受控输入

私有夹具包含模拟连接器、合成文件批次、冻结的增量清单、目标 Schema、期望处理结果与 SHA-256；不保存任何真实连接或业务文件。

## 前置条件

- 连接器凭据由私有密钥管理系统提供，运行记录仅显示脱敏状态；
- 输入、输出和临时资源均位于隔离范围；
- 增量水位、重复策略、失败重试和清理策略已冻结。

## 产品路径

1. 配置受控连接器或选择受控文件批次。
2. 执行接入、解析/处理、写入与 Catalog 保存。
3. 在目标侧核对新增、更新、拒绝和失败记录。
4. 查询输入到输出的追溯关系。
5. 重跑同一批次并验证增量/幂等策略，随后清理。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 无有效授权时接入被拒绝，且不暴露凭据。 |
| A02 | 冻结批次的对象和记录按既定策略全部处理或明确失败。 |
| A03 | 重跑不产生不可解释的重复或遗漏。 |
| A04 | 输出结构与关键汇总符合冻结标准。 |
| A05 | 输入、处理步骤、输出和下游可见产物可相互追溯。 |
| A06 | 失败、重试、部分成功和清理都有可定位状态。 |

## 预期交付物

受控接入摘要、已处理数据/文件、异常清单和输入到输出的追溯记录。

## 运行证据

夹具校验、授权状态、批次计数、增量/幂等检查、输出对账、追溯摘要、失败和清理记录。

## 变更影响

连接器、导入、解析、写表、Catalog 保存、调度、重试、血缘或权限逻辑变更时必须重跑。

## 公开边界

不公开连接器地址、密钥、真实文件、数据、资源标识、工作区、用户或运行日志。
