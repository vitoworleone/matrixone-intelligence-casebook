# SB-DK-008｜混合知识问答与来源归属

| 字段 | 值 |
|---|---|
| 产品域 | 知识库 / Agent / Explore |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证同一知识入口可在结构化数据、非结构化文档和混合问题之间正确选择受控来源，给出可核对答案及引用，并拒绝来源不足的问题。

## 用户目标与风险

用户需要跨数据表和文档获得一个可信答案。风险是混淆来源类型、跨越授权边界、只给自然语言结论不提供证据，或用无依据内容填补空白。

## 受控输入

私有夹具冻结一份合成结构化表、一组文档、独立与混合问题、标准答案、预期来源集合和 SHA-256。

## 前置条件

- 两类数据源均已完成隔离接入及索引；
- 查询身份与可访问范围固定；
- 来源展示和拒答策略可观察。

## 产品路径

1. 创建或绑定同时关联表与文档的知识资产。
2. 配置 Agent/问答入口仅使用该资产。
3. 依次执行结构化、非结构化、混合和无来源问题。
4. 核对回答、引用、查询范围和拒答。

## 可判定验收断言

| ID | 断言 |
|---|---|
| A01 | 结构化问题引用受控表结果；文档问题引用正确片段。 |
| A02 | 混合问题的结论与两类标准答案一致，并区分来源类型。 |
| A03 | 无来源或超授权请求拒答或说明限制，不编造事实。 |
| A04 | 回答不引用未绑定或无权限资产。 |
| A05 | 引用能回到对应的合成表/文档对象，而不是仅显示泛化标签。 |
| A06 | 解绑或清理后，本 Case 资料不可再被本次入口访问。 |

## 预期交付物

四类问题的可核对回答、结构化/非结构化来源归属、清晰的无来源反馈。

## 运行证据

夹具校验、绑定摘要、逐题答案/来源比对、越权与无来源测试、清理记录。

## 变更影响

知识绑定、检索编排、结构化查询、引用、拒答或权限边界变更时必须重跑。

## 公开边界

不公开业务表、文档、真实问题、答案、绑定配置、用户或环境信息。
