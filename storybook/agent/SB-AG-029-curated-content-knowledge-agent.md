# SB-AG-029｜多维内容知识与推荐助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证多来源内容接入、带元数据的检索、来源可追溯改写和规则化推荐的智能体链路。

## 用户目标和风险

内容运营者需要按主题、难度、用途等条件定位材料，并得到可审校的改写或推荐。风险是跨来源混淆、未授权内容泄露、无来源改写和把推荐写成确定性结论。

## 受控输入与前置条件

私有夹具提供合成内容、元数据、许可范围、检索问题、推荐规则和事实基准；仅使用隔离知识库。

## 产品路径

载入受控内容 → 建立检索与标签语义 → 检索并展示来源 → 生成受约束改写或推荐 → 人工核验。

## 明确验收断言

1. 组合筛选只返回符合夹具元数据和授权范围的内容。
2. 改写不添加来源外事实，关键内容可回溯到检索结果。
3. 推荐理由仅引用给定规则和用户条件。
4. 缺少证据或规则时明确标为待确认。

## 预期交付物、证据与变更影响

交付检索结果、来源引用、改写或推荐草案。保留夹具、索引版本与断言。接入、索引、检索、代理或推荐规则变更需重跑。

## 公开边界

不公开内容资产、标签、用户画像、知识库、规则或运行结果。
