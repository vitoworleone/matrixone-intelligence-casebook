# SB-AG-028｜故障群聊复盘提纲

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从受控群聊记录整理事实时间线、待确认项和复盘提纲。

## 用户目标和风险

复盘组织者需要缩短整理时间。风险是把聊天猜测写为事实、遗漏时间顺序或泄露参与者信息。

## 受控输入与前置条件

私有夹具提供合成消息、时间戳、证据标签和基准；不访问真实协作渠道。

## 产品路径

输入受控记录 → 提取事件与证据 → 构建时间线和问题提纲 → 人工校对。

## 明确验收断言

1. 事实、推测和待确认项分开。
2. 时间线与夹具中的顺序一致。
3. 每个事实保留最小来源引用。
4. 不作根因结论或发送复盘材料。

## 预期交付物、证据与变更影响

交付复盘提纲、时间线和待确认项。保留夹具、输出和断言。聊天解析、摘要或模型变更需重跑。

## 公开边界

不公开真实聊天、人员、事件、时间线或内部结论。
