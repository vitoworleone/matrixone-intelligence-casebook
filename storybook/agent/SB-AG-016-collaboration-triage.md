# SB-AG-016｜协作反馈分类与分流

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证助手从授权协作反馈中完成分类、去重、分流和结构化交付。

## 用户目标和风险

维护者需要消化大量反馈而保留原始归属。风险是错误去重、丢失高优先级项、伪造分类依据或直接修改来源记录。

## 受控输入与前置条件

私有夹具包含合成反馈、分类词典、去重基准和优先级规则；外部连接仅可读取。

## 产品路径

读取受控反馈 → 归类与候选去重 → 输出待确认分流表 → 对账异常与遗漏。

## 明确验收断言

1. 每个输出项保留合成来源的可追溯引用。
2. 合并项说明相似依据，不能静默丢弃信息。
3. 不确定分类标记待人工确认。
4. 不对来源系统执行写操作。

## 预期交付物、证据与变更影响

交付分类表、去重理由和待确认队列。保留夹具版本与断言报告。分类规则、连接或模型变更需重跑。

## 公开边界

不公开真实反馈、项目、人员、来源链接或导出文件。
