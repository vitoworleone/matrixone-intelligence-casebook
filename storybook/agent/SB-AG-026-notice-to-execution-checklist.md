# SB-AG-026｜通知解析与执行清单

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从受控通知材料提取行动项、期限、负责人占位和待确认信息。

## 用户目标和风险

使用者需要将长通知转成可执行清单。风险是遗漏约束、虚构责任人或自动创建任务。

## 受控输入与前置条件

私有夹具包含合成通知、术语表、时间表达和行动项基准；不连接邮件或任务系统。

## 产品路径

输入受控通知 → 抽取行动项与依据 → 生成清单 → 标注缺失责任或期限 → 人工确认。

## 明确验收断言

1. 每项行动均可回溯到输入段落。
2. 模糊期限或归属标记待确认。
3. 不添加未提供的责任、优先级或承诺。
4. 不发送通知或创建实际任务。

## 预期交付物、证据与变更影响

交付执行清单、来源映射和待确认项。保留夹具和断言。抽取策略、模型或模板变更需重跑。

## 公开边界

不公开真实通知、邮箱、项目、人员或行动内容。
