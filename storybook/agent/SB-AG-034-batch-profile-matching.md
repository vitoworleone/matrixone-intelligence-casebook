# SB-AG-034｜批量资料匹配与事实归属

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证批量读取受控资料、按明确标准形成事实卡、评分与排序，并防止跨文件事实混淆。

## 用户目标和风险

审核人员需要提升初步匹配效率。风险是将甲资料事实归给乙资料、推断未提供能力、在敏感决策中使用不可解释评分。

## 受控输入与前置条件

私有夹具包含合成资料、匹配标准、事实基准、评分规则和反混淆探针；仅用于人工复核前的辅助分析。

## 产品路径

绑定受控资料与标准 → 提取逐份事实卡 → 匹配评分与排序 → 对账来源归属和反例 → 人工复核。

## 明确验收断言

1. 每项事实、评分依据和排名均可回溯到同一份来源资料与规则。
2. 不得跨文件拼接事实或用未出现的信息补全能力。
3. 标准不清或证据不足时标记待人工确认。
4. 结果仅用于辅助复核，不自动作出最终决定或外发。

## 预期交付物、证据与变更影响

交付逐份事实卡、匹配说明、排序和待确认项。保留夹具、来源映射和断言。解析、匹配、评分或模型变更需重跑。

## 公开边界

不公开资料、个人信息、标准、评分、排序或实际决定。
