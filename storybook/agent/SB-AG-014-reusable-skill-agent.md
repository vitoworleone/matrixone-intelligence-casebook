# SB-AG-014｜可复用专业 Skill 智能体

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证用户上传经审核的专业 Skill 后创建可复用助手候选。

## 用户目标和风险

使用者需要复用领域规则完成受控分析。风险是 Skill 来源不清、越权工具、隐私内容混入或候选绕过人工发布。

## 受控输入与前置条件

私有夹具提供合成 Skill 包、许可声明、示例任务和能力边界；仅允许审阅与候选创建。

## 产品路径

上传受控 Skill → 校验来源、权限与声明 → 创建助手候选 → 审阅能力、限制和工具 → 人工确认前结束。

## 明确验收断言

1. Skill 的来源、版本和声明在候选中可追溯。
2. 候选只暴露 Skill 明示允许的能力与工具。
3. 缺失许可或安全声明时拒绝发布候选。
4. 不能自动对真实数据作出结论或外发结果。

## 预期交付物、证据与变更影响

交付审阅结果、候选定义和限制清单。保留 Skill 摘要、权限快照及断言。Skill、审核策略或代理权限变更需重跑。

## 公开边界

不公开 Skill 文件、领域规则、许可证细节、上传者或真实业务材料。
