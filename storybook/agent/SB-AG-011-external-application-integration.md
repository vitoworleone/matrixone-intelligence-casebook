# SB-AG-011｜外部应用集成助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证助手通过授权外部应用接口接收请求、返回结构化结果和处理失败。

## 用户目标和风险

外部应用需要安全调用智能体能力。风险是权限扩大、输入篡改、重复执行或对调用方泄露内部上下文。

## 受控输入与前置条件

私有夹具提供模拟调用方、签名、请求、响应契约和失败情形；只使用隔离测试凭据。

## 产品路径

授权应用 → 发起受控请求 → 执行助手 → 返回契约化响应与运行状态 → 验证拒绝路径。

## 明确验收断言

1. 请求和响应符合约定 Schema。
2. 未授权、过期或篡改请求被拒绝且不执行。
3. 重试不会重复产生副作用。
4. 响应不包含内部提示词、凭据或无关上下文。

## 预期交付物、证据与变更影响

交付集成结果、状态和错误分类。保留契约版本、审计摘要与断言。认证、接口契约或工具权限变更需重跑。

## 公开边界

不公开真实应用、端点、令牌、请求载荷或审计日志。
