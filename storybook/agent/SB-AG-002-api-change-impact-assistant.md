# SB-AG-002｜接口变更影响分析助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

创建待确认的接口契约变更影响分析助手候选。

## 用户目标和风险

维护者需要识别契约变化对调用方、生成物、测试和文档的影响。风险是遗漏调用链、擅自修改代码或编造兼容策略。

## 受控输入与前置条件

私有夹具包含合成的变更前后契约、调用关系和兼容性原则；助手处于只分析、不可写入的隔离环境。

## 产品路径

输入变更范围与兼容原则 → 创建候选 → 审阅影响矩阵和同步清单 → 人工确认前结束。

## 明确验收断言

1. 输出分别列出契约差异、受影响调用方、生成步骤、测试和文档。
2. 每项影响可回溯到输入契约或调用关系。
3. 对兼容性未知项明确标记，不自动提出或执行兼容层。
4. 候选不具有改代码、改生成物或提交变更的权限。

## 预期交付物、证据与变更影响

交付候选定义、影响矩阵和待确认项。保留输入版本、候选快照和断言记录。契约解析、代码检索或权限模型变更均需重跑。

## 公开边界

不公开真实接口、代码位置、仓库结构、变更内容、人员或内部评审记录。
