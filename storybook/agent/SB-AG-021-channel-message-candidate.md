# SB-AG-021｜协作消息助手候选

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

创建可向授权聊天、邮件或机器人通道发送消息的助手候选，并验证确认门禁。

## 用户目标和风险

使用者需要将信息准确发送至合适渠道。风险是未经确认发信、选错收件目标、重复发送或泄露内容。

## 受控输入与前置条件

私有夹具提供合成消息、测试目标、授权范围和幂等规则；候选创建阶段不允许实际发送。

## 产品路径

声明消息与渠道 → 创建候选 → 审阅授权目标、预览和确认步骤 → 人工确认前结束。

## 明确验收断言

1. 候选将草稿、预览、确认与发送分离。
2. 目标必须来自授权测试集合。
3. 无明确确认时不得投递。
4. 候选展示发送失败与幂等处理规则。

## 预期交付物、证据与变更影响

交付候选定义、消息预览模板和权限清单。保留候选与断言快照。渠道、发送工具或确认策略变更需重跑。

## 公开边界

不公开真实联系人、群组、邮箱、机器人、消息或凭据。
