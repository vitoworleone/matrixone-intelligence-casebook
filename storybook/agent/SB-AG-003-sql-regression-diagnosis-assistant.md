# SB-AG-003｜SQL 回归失败诊断助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

创建用于分流 SQL 回归失败的只读诊断助手候选。

## 用户目标和风险

测试维护者需要从受控失败信息中定位最可能的归类与下一步证据。风险是将猜测写成根因，或建议高风险数据操作。

## 受控输入与前置条件

私有夹具提供合成查询、期望与实际差异、执行摘要和分类基准；助手不得连接数据库或执行语句。

## 产品路径

输入失败材料与禁止动作 → 创建候选 → 审阅分类规则和证据要求 → 人工确认前结束。

## 明确验收断言

1. 将失败区分为语义、结果差异、性能、环境或待确认类别。
2. 每个判断引用输入证据并提供最小复核步骤。
3. 不把缺失日志或数据补为根因。
4. 不生成写入、删除或生产环境执行建议。

## 预期交付物、证据与变更影响

交付诊断候选、分类模板和升级条件。保留候选快照、夹具版本及断言记录。诊断规则、模型或工具权限变更需重跑。

## 公开边界

不公开 SQL、表名、连接信息、真实失败输出或内部任务记录。
