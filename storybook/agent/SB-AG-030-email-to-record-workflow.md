# SB-AG-030｜邮件附件到人工确认记录

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证受控邮件及附件的解析、结构化抽取、人工确认、映射和受限写入草案。

## 用户目标和风险

运营人员需要将多来源附件中的记录转为结构化草稿。风险是跨邮件字段混淆、错误行合并、无人工确认写入，或泄露邮件内容。

## 受控输入与前置条件

私有夹具提供合成邮件链、文档附件、字段 Schema、映射表和标准结果；运行仅使用测试存储。

## 产品路径

导入受控邮件 → 解析正文与附件 → 提取记录和来源 → 人工修订确认 → 生成受限写入预览 → 核验。

## 明确验收断言

1. 每个抽取字段可定位到指定邮件或附件来源。
2. 多行记录保持夹具定义的行序与归属，不跨来源拼接。
3. 匹配不足或置信度不足时进入人工确认队列。
4. 未确认结果不写入目标系统，且测试资源可清理。

## 预期交付物、证据与变更影响

交付结构化草稿、来源引用、确认状态和写入预览。保留夹具、抽取与断言报告。邮件解析、Schema、映射、审批或写入策略变更需重跑。

## 公开边界

不公开真实邮件、附件、订单、字段、映射、业务系统或收件人。
