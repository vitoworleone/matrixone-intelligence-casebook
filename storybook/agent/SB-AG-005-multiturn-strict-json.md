# SB-AG-005｜多轮任务约束与严格 JSON

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证智能体在多轮对话中保持既定约束并输出符合 Schema 的严格 JSON。

## 用户目标和风险

调用方需要机器可读取的稳定结果。风险是上下文漂移、混入说明文字、字段遗漏或用编造值填补未知项。

## 受控输入与前置条件

私有夹具包含多轮合成指令、JSON Schema、禁止项与期望判定；运行使用固定模型和隔离会话。

## 产品路径

建立会话约束 → 发送连续任务与干扰信息 → 请求最终 JSON → 进行 Schema 和语义断言。

## 明确验收断言

1. 最终输出可被严格 JSON 解析且符合给定 Schema。
2. 初始硬约束在后续轮次仍被遵守。
3. 输出不含 Schema 外说明、未授权字段或臆造事实。
4. 缺失信息以规定的未知表达返回。

## 预期交付物、证据与变更影响

交付结构化结果和逐项断言。保留会话转录摘要、Schema 版本及验证报告。模型、提示词、记忆或 JSON 序列化变更需重跑。

## 公开边界

不公开完整提示词、会话内容、模型配置或私有夹具。
