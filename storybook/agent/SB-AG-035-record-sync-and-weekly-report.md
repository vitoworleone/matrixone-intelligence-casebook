# SB-AG-035｜确认记录同步与周期汇总

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证经人工确认的结构化记录同步、统计更新和周期汇总草稿生成。

## 用户目标和风险

运营人员需要减少重复录入与汇总。风险是未确认数据写入、重复同步、计算口径错误或未经确认发送报告。

## 受控输入与前置条件

私有夹具提供合成确认记录、目标 Schema、同步状态、统计规则、周期和报告基准；所有目标均为隔离测试资源。

## 产品路径

审阅确认记录 → 生成同步预览 → 执行一次测试同步 → 更新受控统计 → 生成周期报告预览 → 人工确认后才允许投递。

## 明确验收断言

1. 未确认记录不能进入同步步骤。
2. 同一幂等键不会重复写入或重复累计。
3. 汇总指标可回溯到同步后的受控记录与规则。
4. 报告先预览、后确认；失败阶段和清理状态可核验。

## 预期交付物、证据与变更影响

交付同步预览、统计汇总、报告草稿和审计摘要。保留夹具、幂等、计算和断言记录。Schema、映射、统计、调度或投递变更需重跑。

## 公开边界

不公开记录、业务系统、统计、报告、目标、规则或运行信息。
