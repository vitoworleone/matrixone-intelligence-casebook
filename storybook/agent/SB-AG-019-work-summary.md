# SB-AG-019｜未完成工作汇总

| 字段 | 值 |
|---|---|

| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证助手在授权范围内汇总指定周期的未完成事项。

## 用户目标和风险

使用者需要获得可靠的个人或团队待办摘要。风险是越权读取、误判状态、遗漏过滤条件或泄露协作信息。

## 受控输入与前置条件

私有夹具包含合成任务、授权主体、周期和状态基准；连接仅为读取测试数据。

## 产品路径

声明主体与周期 → 查询受控任务 → 过滤未完成项 → 输出带来源的汇总与待确认项。

## 明确验收断言

1. 结果只包含授权主体和指定周期内的事项。
2. 状态过滤符合夹具定义。
3. 每条结果保留来源与最后更新时间。
4. 不修改或关闭任何任务。

## 预期交付物、证据与变更影响

交付未完成事项摘要和过滤说明。保留授权、查询与断言记录。身份映射、连接或筛选逻辑变更需重跑。

## 公开边界

不公开真实任务、迭代、人员、时间线或协作系统数据。
