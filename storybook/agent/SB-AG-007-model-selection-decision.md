# SB-AG-007｜任务驱动的模型选择建议

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

根据任务约束生成可审阅的模型选择决策树。

## 用户目标和风险

使用者需要在质量、成本、时延、上下文和合规约束之间作选择。风险是编造模型能力、价格或把推荐当成已验证承诺。

## 受控输入与前置条件

私有夹具提供合成任务画像、允许模型能力清单和决策规则；不调用模型服务或修改路由。

## 产品路径

输入任务约束 → 生成决策树 → 审阅选择理由、未知项和验证建议 → 人工决定。

## 明确验收断言

1. 推荐仅基于输入中存在的能力和约束。
2. 输出包含不适用条件、权衡和待验证项。
3. 不虚构价格、吞吐、合规认证或质量基线。
4. 不自动切换生产模型或变更路由。

## 预期交付物、证据与变更影响

交付决策树与验证清单。保留能力清单版本、输出与断言记录。模型目录、选择策略和提示词变更需重跑。

## 公开边界

不公开供应商合同、真实价格、生产路由或模型服务配置。
