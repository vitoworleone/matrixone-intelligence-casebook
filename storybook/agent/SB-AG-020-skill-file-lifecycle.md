# SB-AG-020｜Skill 安装与文件交付

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证经审核 Skill 的安装、受控文件生成、查看和下载生命周期。

## 用户目标和风险

使用者需要从任务得到正确文件。风险是安装未审核能力、生成错误文件、下载越权或遗留临时文件。

## 受控输入与前置条件

私有夹具提供合成 Skill、任务、输出 Schema 和隔离存储；安装需经过权限与来源检查。

## 产品路径

审阅并安装受控 Skill → 处理合成任务 → 生成文件预览 → 授权下载 → 清理临时产物。

## 明确验收断言

1. 只有通过来源和权限校验的 Skill 可安装。
2. 生成物符合约定格式与内容结构。
3. 下载仅对当前授权对象开放。
4. 失败产物和过期临时文件按策略清理。

## 预期交付物、证据与变更影响

交付文件预览、下载状态和清理记录。保留 Skill 版本、产物校验及断言。Skill 运行时、存储授权或下载逻辑变更需重跑。

## 公开边界

不公开 Skill 包、生成文件、存储位置、下载链接或访问记录。
