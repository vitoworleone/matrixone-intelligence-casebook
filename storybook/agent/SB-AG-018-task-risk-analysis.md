# SB-AG-018｜任务风险识别与推进建议

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证助手从项目状态表识别高风险任务并提出可审阅的推进建议。

## 用户目标和风险

项目负责人需要尽早发现阻塞与依赖。风险是把个人信息、主观评价或虚构进度当作事实。

## 受控输入与前置条件

私有夹具提供合成任务状态、依赖关系、日期和风险规则；不连接实际任务系统。

## 产品路径

上传受控状态表 → 请求风险识别 → 返回排序、依据和待确认项 → 与基准核验。

## 明确验收断言

1. 风险排序基于夹具中明示的状态、期限和依赖。
2. 每项建议包含依据、下一步和需要确认的前提。
3. 缺失状态不被猜测为完成或延误。
4. 不输出人员评价或未授权的敏感字段。

## 预期交付物、证据与变更影响

交付风险清单、建议和待确认事项。保留夹具版本、输出及断言。规则、表格解析或模型变更需重跑。

## 公开边界

不公开真实任务、计划、人员、表格或进度数据。
