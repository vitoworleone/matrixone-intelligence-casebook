# SB-AG-004｜SQL 性能回归分析助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

创建分析查询性能回归的助手候选。

## 用户目标和风险

使用者需要解释受控指标中的性能变化并提出验证计划。风险是将相关性误当因果、虚构执行计划或直接给出不可逆调优动作。

## 受控输入与前置条件

私有夹具提供合成基线、对比指标、执行摘要和可接受阈值；不连接真实数据库或监控系统。

## 产品路径

描述目标与限制 → 创建候选 → 审阅指标比较、假设和验证计划 → 人工确认前结束。

## 明确验收断言

1. 输出基线、变化、影响和证据来源。
2. 将事实、假设与待验证项分开。
3. 建议按风险排序的只读验证步骤与回滚前提。
4. 不宣称已定位根因，也不执行调优。

## 预期交付物、证据与变更影响

交付候选定义、性能比较模板与验证计划。保留模型输出和断言记录。指标解释、候选模板和安全策略变更需重跑。

## 公开边界

不公开真实查询、性能数据、系统规模或调优记录。
