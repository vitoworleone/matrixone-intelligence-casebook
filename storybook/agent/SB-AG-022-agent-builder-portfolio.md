# SB-AG-022｜多能力助手候选构建

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证用自然语言创建多个不同职责的助手候选，以及候选的工具、通道和知识边界审阅。

## 用户目标和风险

创建者需要把职责拆分成可审查助手。风险是职责混淆、默认授予过宽权限或直接发布候选。

## 受控输入与前置条件

私有夹具提供合成职责说明、允许能力矩阵和禁止动作；只允许候选创建与审阅。

## 产品路径

输入职责与边界 → 创建候选 → 对照能力矩阵审阅名称、指令、工具和通道 → 人工确认前结束。

## 明确验收断言

1. 每个候选仅覆盖其声明职责。
2. 工具和通道均来自允许矩阵。
3. 候选不可自动发布、执行外部动作或共享数据。
4. 模糊职责被标记为待确认。

## 预期交付物、证据与变更影响

交付候选清单与权限审阅。保留候选快照及断言。构建器、工具目录或权限策略变更需重跑。

## 公开边界

不公开真实候选、人员、通道、配置或内部任务。
