# SB-AG-006｜权威来源调研助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证带外部检索能力的助手基于授权权威来源完成研究摘要。

## 用户目标和风险

使用者需要可核验的时效性研究结论。风险是把非权威网页、过期材料或模型臆测作为事实。

## 受控输入与前置条件

私有夹具冻结允许域名、问题、时间窗口、源文档快照及评分基准；网络访问仅允许至白名单来源。

## 产品路径

声明问题和来源限制 → 检索与阅读来源 → 形成结构化摘要 → 引用核验与拒答检查。

## 明确验收断言

1. 每项关键结论附带可核验来源与获取时间。
2. 不使用未授权来源补足关键事实。
3. 冲突来源被标识，不能静默选择结论。
4. 无证据的内容明确为未知或不予结论。

## 预期交付物、证据与变更影响

交付研究摘要、来源清单与不确定项。保留来源快照标识和判定记录。检索工具、来源政策或模型变更需重跑。

## 公开边界

不公开私有研究对象、检索日志、访问令牌或内部链接。
