# SB-AG-032｜事实约束的多渠道内容生成

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证从受控事实材料生成短摘要、多语言审校稿和可预览排版产物。

## 用户目标和风险

内容运营者需要一源多用的可审校材料。风险是引入来源外定位或数字、术语不一致、字数不达标或格式无法预览。

## 受控输入与前置条件

私有夹具包含合成事实稿、术语表、渠道约束、字数限制和产物基准；不连接发布渠道。

## 产品路径

输入材料与约束 → 提取事实白名单 → 生成短摘要、审校稿和排版草稿 → 预览与事实、术语、长度核验。

## 明确验收断言

1. 关键事实和术语均来自受控材料。
2. 摘要满足规定的长度范围与语气约束。
3. 多语言文本不得新增或改变关键事实。
4. 排版产物满足格式验证；所有产物仅为待发布草稿。

## 预期交付物、证据与变更影响

交付事实白名单、多种内容草稿和格式校验结果。保留夹具、产物指纹与断言。模型、术语规则、渲染或模板变更需重跑。

## 公开边界

不公开原始素材、内容、术语、产物、品牌、渠道或下载地址。
