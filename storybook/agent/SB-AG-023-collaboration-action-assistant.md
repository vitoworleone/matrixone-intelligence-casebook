# SB-AG-023｜代码协作跟进助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证助手从受控代码协作信息生成待跟进事项，并在确认后执行有限协作动作。

## 用户目标和风险

使用者需要减少重复跟进。风险是错误创建事项、向无权目标写入、重复动作或泄露项目内容。

## 受控输入与前置条件

私有夹具提供合成协作事项、允许目标、行动模板和幂等规则；先以预览模式运行。

## 产品路径

读取受控事项 → 生成行动预览 → 人工确认 → 向测试目标执行一次动作 → 核验回执。

## 明确验收断言

1. 写操作前必须呈现目标、内容和影响预览。
2. 仅对授权测试对象执行动作。
3. 幂等键阻止重复创建或重复提醒。
4. 无确认、权限失败或数据缺失时不得写入。

## 预期交付物、证据与变更影响

交付行动预览、回执和失败分类。保留授权和幂等断言。协作接口、权限或模板变更需重跑。

## 公开边界

不公开真实项目、事项、用户、链接、消息或令牌。
