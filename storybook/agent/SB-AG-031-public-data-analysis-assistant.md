# SB-AG-031｜公开结构化数据研判助手

| 字段 | 值 |
|---|---|
| 状态 | `not run` |
| 门禁 | `required` |
| 夹具 | 私有夹具 `v1`；SHA-256 记录于私有验证器 |

## 覆盖范围

验证公开结构化数据的受控载入、加工、问答和数值出处追溯。

## 用户目标和风险

分析人员需要从多维公开统计数据得到可复核的比较与风险信号。风险是指标口径混淆、数值幻觉、无依据排名或将分析视为预测。

## 受控输入与前置条件

私有夹具提供合成公开数据快照、维度表、加工规则、问题集和答案基准；在隔离资源内运行。

## 产品路径

载入受控表 → 加工为分析面板 → 校验结果 → 绑定语义与知识 → 提问并返回数据出处。

## 明确验收断言

1. 问答数值、时间和维度可回溯到加工后的受控数据。
2. 口径不同的指标不得直接混合比较。
3. 缺失或不支持的数据明确表示未知。
4. 不生成确定性预测、信用结论或无来源排名。

## 预期交付物、证据与变更影响

交付受控面板、问答、数据出处和限制说明。保留夹具、加工版本与断言。载入、SQL、语义、检索或模型变更需重跑。

## 公开边界

不公开原始数据文件、连接、查询、账户、资源或运行报告。
