# SB-WF-002｜系统算子的可发现、可配置与可验证

| 字段 | 值 |
|---|---|
| 产品域 | 工作流 / 系统能力 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证面向用户的系统能力在工作流画布中可发现、可配置、可运行并能输出可判定结果。单项能力由对应专项 Case 覆盖。

## 用户目标与风险

用户需要选择正确能力完成处理。风险是能力目录缺失或重复、配置说明不足、权限错误、运行结果不可观察或隐藏失败。

## 受控输入与前置条件

私有清单冻结可见能力、分类、最小输入、必填配置和对应专项 Case；夹具版本与 SHA-256 可追溯。需有隔离工作流和最小权限。

## 产品路径

在工作流编辑器搜索并拖入能力；配置最小输入与输出；连接上下游；保存并运行；查看节点详情和产物。

## 验收断言

- 可见能力与冻结清单一致，分类、名称和用途清晰，无未授权能力泄露。
- 每项能力的必填配置、输入校验、运行状态和失败提示可观察。
- 专项 Case 通过前，目录覆盖 Case 不得标为通过。
- 节点输出能交给下游或在指定目标位置核对；资源可清理。

## 预期交付物、运行证据与变更影响

交付物为能力覆盖矩阵和最小运行摘要。证据包括目录快照、配置校验、运行终态、专项证据链接和清理记录。变更能力注册、目录、权限或节点界面时必须重跑。

## 公开边界

不公开内部能力标识、实现、环境、资源或日志。
