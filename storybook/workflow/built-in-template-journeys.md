# SB-WF-001｜内置工作流模板的全景回归

| 字段 | 值 |
|---|---|
| 产品域 | 工作流 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `ready` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证用户可从工作流入口发现、选择、配置、运行并核对当前受支持的内置模板；各模板的业务结果由对应专项 Case 判定。

## 用户目标与风险

用户希望可靠地从模板开始完成任务。风险是入口不可见、模板参数错误、保存后配置丢失、运行不可追溯或模板升级造成已有路径退化。

## 受控输入与前置条件

私有夹具维护受支持模板清单、每个模板的最小合成输入、必填参数和预期终态，均以版本和 SHA-256 冻结。需具备隔离工作区和所需最小资源。

## 产品路径

进入工作流创建页；逐一选择模板；填写最小必填参数；保存并运行；在执行详情与目标产物位置核对状态。

## 验收断言

- 受支持模板均可发现，并展示准确的名称、用途和必填配置。
- 合法最小配置可保存和运行；非法或缺失配置有可定位提示。
- 运行后的模板、参数摘要、阶段状态和输出位置可追溯。
- 模板清单与专项 Case 清单一致；缺失专项验证视为门禁阻塞。
- 临时资源清理完成。

## 预期交付物、运行证据与变更影响

交付物是模板覆盖矩阵与逐项运行摘要。`pass` 需保存清单快照、配置校验、运行终态、专项 Case 引用和清理记录。变更模板、默认参数、创建页或执行编排时必须重跑。

## 公开边界

不公开内部模板标识、环境、资源、用户、实现路径或运行日志。
