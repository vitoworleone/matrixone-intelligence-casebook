# SB-WF-013｜受控通用检索步骤

| 字段 | 值 |
|---|---|
| 产品域 | 工作流 / 信息检索 |
| Case 类型 | 端到端产品回归 |
| 内容状态 | `draft` |
| 门禁级别 | `required` |
| 当前运行结果 | `not run` |

## 覆盖范围

验证工作流中的通用检索步骤可接收固定查询，在批准的受控语料或测试服务内完成检索，并将可引用的结果交给下游节点。

## 用户目标与风险

用户要让工作流在明确范围内获得信息。风险是查询被错误改写、范围失控、结果不可复现、无来源摘要、异常或空结果被伪装为成功。

## 受控输入与前置条件

私有夹具提供冻结的合成语料/Mock 服务、固定查询、预期命中、排序规则与错误样例，并记录版本和 SHA-256。运行必须使用批准的受控范围，不依赖公开互联网或生产数据。

## 产品路径

在工作流添加检索步骤；配置受控检索范围、固定查询和输出字段；保存并运行；在节点详情和下游结果中核对命中、引用和失败状态。

## 验收断言

- 固定查询在受控范围内返回标准命中，顺序、字段和来源符合合同。
- 空结果、无效查询、范围不可用和超时均有明确终态，且不得生成虚构摘要。
- 下游仅接收经过合同校验的结果，并能回链到查询、来源和本次运行。
- 运行不访问未批准的数据源；测试资源可清理。

## 预期交付物、运行证据与变更影响

交付物为检索结果、来源摘要和节点状态。证据包括夹具校验、查询/命中比对、范围审计、错误分类和清理记录。变更查询解析、检索器、排序、权限、缓存或节点编排时必须重跑。

## 公开边界

不公开查询、语料、服务地址、访问规则、环境、资源或日志。
