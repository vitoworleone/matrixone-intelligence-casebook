# SB-WF-007｜对象存储与原始文件的数据载入

## 覆盖范围

验证受控对象存储或原始文件可被发现、读取、校验并载入隔离数据资产，且能记录文件与载入结果的对应关系。

## 用户目标与风险

用户要稳定引入外部数据。风险是漏载、重复载入、格式错误、断点恢复不可靠、源/目标不一致或访问凭据暴露。

## 受控输入与前置条件

私有夹具为合成对象、文件清单、校验值、目标结构和标准载入结果。连接授权由环境安全注入；夹具版本与 SHA-256 固定。

## 产品路径

配置已批准数据源和输入清单；选择目标资产与载入策略；运行；在执行详情、目标资产和导入摘要中对账。

## 验收断言

- 指定对象均被读取并完成校验；遗漏、重复、损坏和不支持格式有明确状态。
- 目标记录/文件与标准结果一致，来源、批次和运行可追溯。
- 失败重跑遵循幂等策略，不造成意外重复；临时资产可清理。
- 凭据不会出现在配置摘要、输出或证据中。

## 预期交付物、运行证据与变更影响

交付物是导入摘要、目标对账和来源记录。证据包括输入校验、对象清单、行/文件统计、异常分类和清理记录。变更存储连接、读取、格式解析、载入或幂等逻辑时必须重跑。

## 公开边界

不公开存储位置、文件、连接、凭据、目标资产、环境或日志。
