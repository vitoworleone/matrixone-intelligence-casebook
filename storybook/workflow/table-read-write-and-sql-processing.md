## 覆盖范围

验证受控数据表可被读取，经过受控 SQL 或映射处理后准确写入隔离目标表。

## 用户目标与风险

用户要将表数据用于自动处理。风险是读取范围错、SQL 产生意外修改、类型转换错误、重复写入、事务失败或结果不可对账。

## 受控输入与前置条件

私有夹具包括基线表、输入记录、允许 SQL、目标表结构和标准结果，并以版本和 SHA-256 冻结。运行应使用隔离的只读源与可写目标。

## 产品路径

选择源表；配置读取范围、SQL/映射和目标表；保存并运行；在节点详情与目标表核对数据与写入摘要。

## 验收断言

- 读取结果与受控源表一致；无权限、语法错误和非法写入被明确阻止或提示。
- 处理结果的行数、主键、字段类型和值与标准答案一致。
- 重跑策略符合约定，不产生未授权重复记录；写入状态可追溯。
- 测试表和临时资源清理完成。

## 预期交付物、运行证据与变更影响

交付物是处理结果表、行级对账和执行摘要。证据包括夹具校验、读取/写入统计、查询结果比对、失败分类和清理记录。变更读取、SQL 执行、映射、写入或事务逻辑时必须重跑。

## 公开边界

不公开 SQL、表结构、数据、连接、资源标识或日志。
