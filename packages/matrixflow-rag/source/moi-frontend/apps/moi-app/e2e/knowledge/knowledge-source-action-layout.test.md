# 知识库数据源操作列布局 E2E

## 前置条件

- 使用 mock 模式进入工作区 `/ws-001/knowledge/9002/edit`。
- 知识库返回四条 `source_type: table` 的 SQL Server 表来源和一个非结构化文件来源，且均已处理完成。

## 验收点

1. 在 issue 同尺寸的 `1502x667` 视口，结构化表操作列显示 `SQL`、有效期、下载和删除；文件来源显示有效期、下载和删除。
2. 操作列在所有视口均为 Ant Design Table 的右固定列，横向滚动中保持可见。
3. 四个操作的实际边界均在操作单元格内，不贴边或裁切。
4. 测试保留右滚到底的 Chromium 截图作为视觉回归证据。
5. 在 `1440x900` 与默认展开侧栏的 `390x844` 视口中，两类来源的操作列均完整可达，且移动端页面根节点不产生横向滚动。

## 状态边界

- 本用例覆盖 issue 对应的成功态布局。
- 空、加载、错误和权限拒绝状态不改变操作列的列宽或固定策略，已由页面现有状态处理覆盖。
