# 数据侧知识库创建弹窗

## 前置条件

- 使用 mock 模式登录并进入工作区 `/ws-001/knowledge`。
- 本用例只覆盖数据侧知识库页面，不覆盖智能体入口的来源选择流程。

## 用例

| #   | 场景     | 操作步骤                       | 预期结果                                                     |
| --- | -------- | ------------------------------ | ------------------------------------------------------------ |
| 1   | 基本信息 | 打开新建知识库                 | 保留原大尺寸创建弹窗，仅显示基本信息和高级图片索引选项；不显示第二步或来源选择 |
| 2   | 桌面视口 | 在 1440×900 视口打开新建知识库 | 弹窗完整位于视口内，并保留截图证据                           |
| 3   | 移动视口 | 切换为 390×844                 | 弹窗完整位于视口内，无横向或纵向溢出，并保留截图证据         |
| 4   | 创建请求 | 填写基本信息并点击完成         | 请求 `create-empty`，不携带 `sources` 或 `source_selections` |

## 边界说明

- 数据侧创建请求只提交基本信息与图片索引开关；来源选择保留在智能体侧流程，不在本用例范围内。
