CDH Simple Data 表说明：
cdh_simple_data 表存储从 Cloudera Data Hub (Hive) 导入的测试数据。
表结构：id (整数，主键), value (字符串，数据值)。
该表位于 ecommerce_demo 数据库中。

数据来源：
数据通过 cdh-to-mo workflow 从 Hive 的 export_test.simple_data 表同步到 MatrixOne。
同步过程使用 Parquet 格式作为中间存储，通过 S3 传输。

查询示例：
- 查询所有数据：SELECT * FROM cdh_simple_data
- 按 id 排序：SELECT * FROM cdh_simple_data ORDER BY id
- 统计数据量：SELECT COUNT(*) FROM cdh_simple_data
- 查询特定值：SELECT * FROM cdh_simple_data WHERE value LIKE '%keyword%'
