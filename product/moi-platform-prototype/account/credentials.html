两种使用方式
方式一 · OAuth 换取令牌推荐 · 平台 API
用 Client ID + Secret 换取短时访问令牌（约 1 小时，过期重新换取），再以 Bearer 调用 MOI 平台 API。MOI SDK / CLI 会自动完成换取与刷新。
POST https://auth.moi.matrixorigin.cn/oidc/v1/token grant_type=client_credentials&client_id=$CLIENT_ID&client_secret=$SECRET → { "access_token": "…", "expires_in": 3600 }
方式二 · API Key 直调OpenAI 兼容 · Genesis
在列表「凭据」中为该服务账号创建 API Key（最多 15 个、各自设有效期、可单独删除），填入 Cursor、OpenAI SDK 等只认「一把 Key」的工具，调用 Genesis 模型服务。注意：Secret 仅用于换取令牌，不要直接当 Key 使用。
Base URL https://api-taas.moi.matrixorigin.cn/v1 API Key moi_sk_…（该服务账号的 API Key）
