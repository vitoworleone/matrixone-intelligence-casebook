# Public Release and Confidentiality Boundary

## Purpose

This repository presents independently recreated product cases for learning and portfolio discussion. It is not a mirror, export, backup, or derivative document repository for any employer or customer.

## Never commit

- Customer names, identifiers, contact details, contracts, SOWs, invoices, source documents, or delivery records.
- Employer source code, internal PRDs, roadmaps, pricing, sales material, product screenshots, credentials, endpoints, or non-public metrics.
- Data that is merely labelled "desensitized" without confirmed permission for public release.
- Third-party documents, images, datasets, or code without a compatible public license.

## Required before publication

1. Recreate the artifact rather than copying its original file or image.
2. Replace names, dates, versions, internal terminology, screenshots, and data with generic or synthetic equivalents.
3. Verify that every statement about personal contribution is factual and can be explained in an interview.
4. Record the source and license for every public dataset or external visual asset.
5. Run the future `scripts/verify-public-release/` checks and perform a manual review.

## Naming

Use the MatrixOne Intelligence name, logo, or other trademarks only when their public use has been approved. Otherwise use the neutral repository name `enterprise-ai-casebook`.
